# 统一后端：读库接口与管理页开发预览

日期：2026-10-01。这是独立重写后端的可运行开发切片，**完整抖音 MVP 仍在实施**。实际验收与所有缺口统一见[实施记录](2026-10-01-抖音上下文MVP-实施与实际验收记录.md)。

## 1. 当前能做什么

最新前端修订：用户指定直接复用自己原 RedNote Desk 的组件，而不是另做同色界面。已恢复原表单、按钮、结果卡片、双栏详情及 JSON 面板，业务接口仍接统一后端；原完整 CSS 已用哈希锁定。实际浏览器与关联 92 项测试证据见 [RedNote 迁移记录](2026-10-01-RedNote前端迁移与并行验收.md)。此前仅主题迁移未获用户验收，不沿用为已接受的 UI。

最新单作品页面更新：主人可粘贴一个作品链接或分享文字，明确选择下载并确认后登记持久任务；纯模型后台不会执行，来源后台须另外授权。重复提交复用原任务，不自动扩大到博主；原文、附件和提取分开显示，可从结果直接打开原文。`add-link` 前台CLI与 `submit-link` 排队CLI、页面共用自有单条工作流。此来源确认不启用自动提取，但若此前另行启用了有额度的自动规则，新增媒体仍按该原规则处理。恢复保留检查点，受阻/部分完成不自动重试。独立安装的当前证据详见实施记录；旧缺口段落按各批次时间理解。

最新页面连接更新：服务器显式启用后，主人可从页面发起独立登录、已有登录验证、收藏夹发现及取消。实际可见浏览器及页面的原创拦截数据流程通过；启动中与浏览器就绪分开显示，仍须真实平台登录/夹兼容验收。该次首次启动约25秒，冷启动尚待优化。后面的前批“网页窗口未接通”按本次更新理解，不能读成所有真实来源已可用。

最新本人范围更新：添加页已能刷新本产品保存的账号证明，并确认登记本人喜欢/收藏或已观察收藏夹，保存不执行同步或推理。独立安装的实际CLI/浏览器以原创拦截响应完成两页发现和选择验证；真实收藏夹端点/字段兼容尚未证明，网页开启登录窗口仍缺。下文较早的缺口说明按本更新及实施记录理解。

后续实施更新：处理页已接自有持久工作流与三个模型角色配置；添加页已接范围登记与定时规则；两页已有后台内核所有权/权限快照，下文早期读库实测仍保留为历史证据。主人管理口令可设置新增自动规则、显式选择1～20份已准备媒体的历史批次、查看分页任务与取消后续阶段、预览确认恢复选定暂停积压。本人平台登录与收藏夹发现尚未接页面；后台健康心跳、模型真实能力测试与加密系统凭据库未完成，不冒充全部流程完成。当前结果见实施记录。

新模块 `backend/src/collection_context/` 提供文件库、关键词索引、来源关系、证据版本，以及统一搜索/读取/状态。CLI、stdio MCP、HTTP 和网页共用应用服务，没有调用旧 `app`、dYm、All-IN-ONE 或百炼 CLI。通用协议 SDK 和文件/媒体组件正常复用。

网页包含三个入口：

- 我的资料：真实库列表、来源筛选、关键词搜索、原文/转写/画面/总结等分开读取；缺失、过期和校验问题明确显示。
- 添加与连接：登记完整博主主页、每批1～20条与是否下载；分页查看已有喜欢/收藏/收藏夹/博主固定范围；主人确认后手动排队、启用或暂停60～1440分钟定时，受阻后须明确重新尝试。范围保存不访问平台，页面不执行同步或模型；必须另行启动已授权后台。本人登录、收藏夹发现/选择和单作品链接的页面入口仍未接通，不假装可用。
- 处理与设置：显示资料/转写缺项、主人授权的自动规则、历史提交、任务阶段/调用数量/未知结果与取消恢复；显式启用后可配置音频、视觉、总结的地址/模型/协议/参数与新密钥。页面不读取或回显已保存密钥、不直接推理；任务执行器必须另行启动并获授权。保存配置不验证云端能力、不产生推理费用。

资料是文字证据，不作为执行授权；收藏关系不自动成为个人观点或固定画像。查询不产生模型请求、任务或写入。当前查询仍是关键词检索，精度/语义检索/完整视频提取不因本页可用而视为完成。

旧命令 `content-context` / `content-context-mcp` 和旧生产库继续保留。新模块使用带 `workspace_id` 的独立工作目录，尚未支持旧库直接迁移；不要对旧库运行初始化。

## 2. 安装与本地启动（候选包，不是已发布的 pip 产品）

2026-10-02安装更新：独立Mac候选已带Playwright SDK及包内Node／JS；固定组件安装CLI与新空白浏览器探测已实际通过。桌面新增“安装运行组件”清单与单项二次确认，安装和服务互斥，停止／退出等真实安装线程结束，不扩大四项授权。Mac14+ ARM64已核实无桌面浏览器及可见浏览器开发候选；后者完整官方包下载／固定布局安装／源码和冻结程序的本机渲染退出均有证据，真实平台登录仍未验收。FFmpeg配对、OCR、全部组件GUI安装和其他平台的完整安装仍未完成。安装／探测使用库外目录，不要求资料库已存在，不启用同步或计费；签名、公证与发行许可仍待完成。命令和精确边界见[原生构建与组件安装说明](../../backend/tools/native_distribution/README.md)，实际下载／冻结运行及窗口证据见实施记录；不要把本机源码环境已装工具当成新用户拥有运行环境。

本批来源页面验证环境为 macOS Python 3.12.13。Linux ARM64曾验证较早候选的核心/页面与媒体，不能外推本批来源页面；Windows安全文件、Linux x64和完整三平台发行仍未完成。三平台仍属于完整交付要求。

将审核后的独立 wheel 安装到新隔离环境，启用需要的 `web` / `mcp` 可选依赖。包尚未公开发布，不把内部 `content-agent-backend` 包作为公开产品安装包。

下面示例中的 `./collection-workspace` 必须是你新建的空目录；它与现有 Obsidian 内容库、旧工作目录分开。初始化拒绝覆盖非空目录。

```bash
collection-context --workspace ./collection-workspace init
collection-context --workspace ./collection-workspace access-key --name "本机管理页" --ui
collection-context-web --workspace ./collection-workspace
```

第二条命令在你自己的终端一次性显示随机的**产品访问口令**。自行保存，别贴到聊天、截图或仓库；服务器只保存 SHA-256 摘要。这与抖音密码、上游模型 API Key、New API 下游 Key 各自独立。`--ui` 只允许建立页面会话，不授予同步/处理/计费权限。

默认页面：`http://127.0.0.1:8787/`。仅监听回环，不替换现有 8765 控制台或 8001 公众号服务。新空库如实显示零条，不暗中导入私人资料；主人可以登记博主范围，执行仍须独立连接及后台授权。

本机桌面开启主人页面连接（开发候选；账号浏览器单独放在库外）：

```bash
collection-context --workspace ./collection-workspace access-key --name "主人管理" --ui --manage
collection-context-web --workspace ./collection-workspace --allow-source-connect --browser-dir ./collection-browser
```

页面先勾选本次平台访问，再打开独立登录；窗口出现在后台所在电脑，并非访问页面的手机上。完成平台要求后验证本人账号，按需点“发现收藏夹”；收藏夹兼容候选尚需实际账号核对。无桌面后台加 `--source-connect-headless` 只检查已存在的本产品独立登录，不开可见窗口；远程模式拒绝可见窗口方式，首次登录/续期仍未验证。不填路径配对或目录与库重叠会拒绝，页面不能指定任意路径。连接操作不同步作品、不执行模型，原后台执行授权保持独立。

如需撤销口令：

```bash
collection-context --workspace ./collection-workspace revoke-access --principal "<创建时返回的principal>"
```

活动服务器每次请求重新核对访问规则，撤销后令牌和已建立会话均被拒绝。访问规则损坏或磁盘不可读时停止授权，不沿用旧权限。口令无法从摘要恢复，丢失后应撤销并重新创建。

## 3. 现有资料查询

资料写入或变化后，自有事务在内容提交后维护派生索引。任务进度不使内容索引失效；查询不会触发写入或模型提取。索引损坏或维护失败时，由本地所有者显式重建。

```bash
collection-context --workspace ./collection-workspace rebuild-index
collection-context --workspace ./collection-workspace search --query "UI 390" --limit 3
collection-context --workspace ./collection-workspace search --query "UI 390" --limit 3 --offset "<上一页next_offset>" --version "<上一页version>"
collection-context --workspace ./collection-workspace read --ref "<material_ref>" --artifact screen --max-chars 2000
collection-context --workspace ./collection-workspace status --ref "<material_ref>"
```

读取产物：`original/audio/screen/summary/readable/image/user_note`。继续正文必须同时传上一页 `version` 与 `next_offset`，上限 20,000 字符；资料被排除后已知引用也不可读。人工编辑后的文件在主人确认接纳前拒绝读取，不返回缓存旧文；接纳入口见下节。

### 核对外部编辑的正文

只针对已经登记的七类 Markdown 产物，不接收任意文件路径，不修改平台来源元数据。库主人在本地编辑对应附件后，可以在资料详情的“资料管理”选择“核对正文类型”，点击“核对外部编辑”。页面显示修改后正文前 2000 字及哪些派生产物会过期；超过预览长度需自行核对本地全文。旧文件已经被编辑，不假造修改前逐行差异。

命令行同一能力，先预览，再使用返回的 `preview_token` 明确确认：

```bash
collection-context --workspace ./collection-workspace accept-edit --ref "<material_ref>" --artifact screen
collection-context --workspace ./collection-workspace accept-edit --ref "<material_ref>" --artifact screen --preview-token "<preview_token>" --confirm-edit
```

确认保存修改正文的新快照、保留原编辑文件、更新索引，不调用模型。音频／画面／图片／原文修改使已有总结与可读内容过期；总结修改使可读内容过期；备注独立保留。过期输入上的修正不会自动变成当前输入的结果，覆盖与准确率依旧未核验。预览后资料／文件发生变化、主人授权撤销或存在排队／运行任务时拒绝接纳；未改变的文件不创建重复版本。

确认过的人工修改随备份恢复保存，正常提取在解析模型密钥／调用模型前拒绝直接覆盖；自动队列将该资料记录为待处理问题，不阻塞其他资料。仅重新生成总结使用下面的单独确认入口。只读 AI 与添加 AI 无接纳权限；HTTP 接纳要求主人页面会话与 CSRF。自动生成的素材入口卡、未登记文件、批量旧库导入不由此入口接纳；这些文件继续保留并报告缺口。

### 只更新总结，保留修正后的正文

先接纳外部编辑，再在同一“资料管理”点击“仅更新总结”。预览展示当前总结模型、上传的已保存正文类型、仍缺失或过期的证据及最多一次模型请求；费用无法确定时显示未知。勾选上传及费用授权后排队，只有另行允许模型调用的后台才执行。它只更新总结与可读内容，不重跑音频／视觉、不上传用户备注、不下载原媒体。已人工修改的总结或可读内容默认拒绝替换，没有强制覆盖开关。

```bash
collection-context --workspace ./collection-workspace refresh-summary --ref "<material_ref>"
collection-context --workspace ./collection-workspace refresh-summary --ref "<material_ref>" --preview-token "<preview_token>" --idempotency-key "<本次唯一任务标识>" --confirm-fee
```

任务固定确认时的正文／产物版本和总结模型。源证据在请求过程中变化时，已知用量保留、发布失败且旧总结保留；不自动再计费。未知请求结果阻止重复发送；同一任务恢复或相同有效输入可复用已确认结果，不能将复用说成新模型调用。新总结沿用证据覆盖缺口及未核验精度，引用 `t_` 是整个已登记文本快照，不是假造视频时间点。旧模型内部缓存或旧总结不作新的修正证据。

总结／可读内容保存来源产物版本与哈希，正文再次变化时返回过期或待核对，不从搜索索引返回旧内容冒充当前结果。备份异路径恢复保留此关联和人工修正；本轮只完成隔离样例验证，不代表真实云模型质量或三端发行已验收。HTTP 同样要求主人 Cookie／CSRF，默认只读／添加 AI 不能排队这项计费处理。

搜索每页最多20条，返回 `version/offset/next_offset/has_more/total_matches`。`next_offset=null` 表示本次匹配已读完，不代表全部收藏已经提取；范围覆盖及完整性缺口仍看响应中的 `scope_coverage/integrity_gaps`。继续时保持相同搜索词及筛选，携带上一页版本；页大小可调整。查询、筛选、已提交内容或候选证据完整性变化返回 `version_changed`，从第一页重搜，不能把新旧两页直接拼接。后台任务进度和同内容显式重建索引不会单独使搜索页失效。管理页搜索与列表均可点“继续查看”。

时间查询需明确 `--time-basis action_at/published_at/first_observed_at/last_observed_at`。未知真实操作时间不进入“确定最近点赞”的时间筛选；博主作品关系也不冒充用户喜欢。

### 旧资料引用映射

旧入口返回的 `m1:` 引用可以由库主人明确关联到**已存在的新资料**。先核对同一作品，再预览，不会读取旧卡路径：

```bash
collection-context --workspace ./collection-workspace bind-legacy-ref --legacy-ref "<旧m1引用>" --ref "<新material_ref>"
collection-context --workspace ./collection-workspace bind-legacy-ref --legacy-ref "<旧m1引用>" --ref "<新material_ref>" --preview-token "<上一步preview_token>" --confirm-binding
```

确认后，原 `read/status` 及 CLI、MCP、认证 HTTP 可使用旧引用；响应统一返回新稳定引用。正文续读继续携带上次版本；排除、产物编辑核对与范围限制仍生效。相同旧引用不得覆盖到另一条作品，最多10,000个映射。预览后目标正文变化须重新预览；只读和单链接添加AI工具没有创建映射权限。

映射随资料库备份恢复，但**不是旧库布局接入或批量导入已完成**：不会导入原卡正文、未登记附件、登录态或模型密钥，不自动发现/连接私人库。首版仅接受旧抖音素材卡引用；旧 `card/video/verification` 产物不转换成新产物类型。不要求改名旧文件；未映射时返回 `legacy_reference_unmapped` 与库主人核对提示，不猜测解码路径。

## 4. AI 接入

同一设备上的 AI 可启动：

```bash
collection-context-mcp --workspace ./collection-workspace
```

stdio 本身不另开网络端口，由宿主启动并限定库位置；只注册 `search_collections`、`read_collection`、`collection_status` 三个工具。工具默认只读。业务错误通过 `isError=true` 和结构化错误返回，遵循 [MCP 工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。

### 可选：允许 AI 添加一条作品

主人在本地单独创建可撤销的产品访问口令：

```bash
collection-context --workspace ./collection-workspace access-key --name "我的AI单链接" --add
```

口令只显示一次，由用户在宿主的私有环境配置里设为 `COLLECTION_CONTEXT_ACCESS_TOKEN`，不要写进命令参数、分享的配置、资料库或聊天。它不是模型 Key；不要给 AI 主人管理口令。默认读口令没有添加权限，原口令不会被自动升级。

显式启用可选 MCP 添加包：

```bash
collection-context-mcp --workspace ./collection-workspace --allow-add
```

只有 `--allow-add` 与有效的添加口令同时存在才增加 `add_collection(url, idempotency_key)`、`get_job(job_id)`，合计五个工具；单独设置环境变量不改变默认三个只读工具。CLI 的 `agent-add --url ... --idempotency-key ...`、`agent-job --job-id ...` 使用同一环境口令与业务入口。

HTTP 对应 `POST /v1/collections`，正文严格只含 `url`、`idempotency_key`；排队返回202与 `job_id`，不等待完整来源读取。`GET /v1/jobs/{job_id}` 仅返回当前凭据登记的添加任务，其他身份或主人任务不可见。相同身份的重试使用相同幂等键；更换参数返回冲突，不要不断换键重试。每个身份最多五个未完成任务。

本批添加只保存平台原文，不下载媒体、不运行模型，不能批量同步、取消、删除或修改模型配置。主人已开启自动提取也不会自动给 AI 新建资料授予费用权限。执行来源观察仍需主人独立开启自有后台：

```bash
collection-context --workspace ./collection-workspace worker --allow-source-sync --browser-dir ./collection-browser
```

未启动来源后台时保持排队；纯模型后台不会执行它。后台不借用第三方账户目录。口令撤销后后续提交/状态请求被拒绝，排队任务受阻，运行中在后续观察、每次资料提交及成功终态检查权限；已完成的来源读取和此前保存的资料无法追溯撤销。`revoke-access --principal <创建时返回的身份>` 不会清用户历史。默认本机只读 stdio 是宿主授予文件访问的本地进程，不是远程 Bearer 账户；撤销添加口令并不删除原有只读能力。

本批实际 MCP SDK 客户端、HTTP、独立浏览器后台子进程通过原创建库验收；不等于宿主 AI 的自然语言问答或真实抖音兼容已验收。详见实施记录。

认证 HTTP 同用例：

| 操作 | 路径 | 输入 |
| --- | --- | --- |
| 搜索 | `POST /v1/collections/search` | query、limit、filters、offset、version |
| 读取 | `POST /v1/collections/read` | material_ref、artifact、offset、max_chars、version |
| 状态 | `GET /v1/collections/{material_ref}/status` | 受控引用 |
| 网页列表 | `POST /v1/collections/list` | limit、offset、version、filters |
| 网页总览 | `GET /v1/collections/overview` | 无参数 |

程序读访问须 `Authorization: Bearer <产品访问口令>`；不要将口令写进 URL 或固定源码。网页使用短期 HttpOnly / SameSite=Strict 会话，写方法还要求对应 CSRF 值；口令不进入 localStorage，来源正文只通过 textContent 渲染。请求/响应限长、并发及频率受限，无任意路径读取或任意 shell；读接口不会提交任务或产生费用。

主人管理另行授权：仅本机 CLI 显式 `access-key --name "主人管理" --ui --manage` 创建管理口令，不提升已有AI或页面只读口令。管理口令代表库主人操作权限，勿提供给AI；模型密钥与它不同。`POST /v1/management/{action}` 同时要求 `ui:manage`、有效页面会话及 CSRF，不接受 Bearer 程序调用。处理动作有 `overview`、`automatic`、`history`、`cancel`、`resume-preview`、`resume`；来源和模型动作见下表。参数严格校验，不允许原始任务JSON、shell或凭据路径。启用自动、提交历史、恢复积压都需要明确 `fee_confirmed=true`；确认的是调用次数上限，价格未知不显示0元。历史重复提交采用稳定幂等键，预览恢复采用状态绑定令牌。新规则不会放行全部旧积压，取消不保证退回已发出请求的费用。撤销口令对正在服务的后续请求立即生效。

普通调用示例使用标准包络 `ok/data/error/meta`。MCP 的证据也带 `content_untrusted`；AI 搜索后继续读原始证据，不能只引用机器总结，更不能把库内命令当成用户要求执行。

### 来源页面的新增主人动作

这些仍是同一 `POST /v1/management/{action}` 页面会话边界，不向默认AI工具或Bearer调用开放。

| 动作 | 字段 | 行为 |
| --- | --- | --- |
| `link-submit` | `url/download/idempotency_key/source_confirmed` | 规范化一个官方作品或短链接，确认后零模型预算排队；不扩到博主。重复键复用、相同规范链接另一进行中任务拒绝；不访问平台或模型 |
| `link-status` | `job_id` | 仅主人单链接任务，原文/媒体状态和受控引用分开；不读取下载签名、私有目录或模型秘密 |
| `sources` | 可选 `offset` | 每页20个当前固定范围、真实任务及固定定时状态；不返回本人账号引用或登录凭据 |
| `connection` | 无 | 仅本地证明的版本/名字/时间/已观察夹/覆盖；不返回账号引用或Cookie，不访问平台 |
| `connection-run` | 无 | 当前服务器的连接线程状态/身份/启动与就绪时间；默认disabled，刷新不访问平台 |
| `connection-start` | `mode/source_confirmed` | 仅login/check/folders，显式启动配置及主人确认后异步观察；不接路径/命令/秘密，重复进行中拒绝 |
| `connection-cancel` | `run_id` | 仅确切本次观察，停止请求在页面边界生效；不保证撤回已确认的观察 |
| `self-source-create` | `kind/collection_id/connection_version/limit/download/source_confirmed` | 仅本人liked/saved/collection；有效证明及确切版本，夹须在当前观察列表中；同写事务复核，保存不排队/调用模型 |
| `source-create` | `creator_url/limit/download` | 仅完整官方博主主页；去掉分享参数，同配置可重复，不覆盖既有不同配置 |
| `source-submit` | `config_id/idempotency_key/source_confirmed` | 明确确认后原子排队，固定0模型预算；重复幂等键复用，同范围另一未完成批次或页面旧配置拒绝新排队 |
| `source-timer` | `config_id/enabled/interval_minutes/reset_blocked/source_confirmed` | 开启需确认来源权限；关闭不取消手动批次、不改原固定范围。受阻不自动重试，重新尝试需显式 `reset_blocked=true` |

已登记范围不等于已登录、后台在线或同步成功。定时可能仍绑定早期配置，页面明确显示差异；暂停使用原固定版本，任务不会热切换。每批数量、是否下载和历史覆盖限制在提交前展示。收费提取须另行设置，不因来源同步授权自动开启。

单条排队CLI示例（仅用于新产品库）：

```bash
collection-context --workspace ./collection-workspace submit-link --url "https://www.douyin.com/video/<作品数字ID>" --idempotency-key "单条-本次固定标识" --allow-source-sync
collection-context --workspace ./collection-workspace worker --allow-source-sync --browser-dir ./collection-browser --once
collection-context --workspace ./collection-workspace job-status --job-id "<返回的job_id>"
```

默认不下载；确认需要本地媒体时在 `submit-link` 增加 `--download`。浏览器目录与资料库分开，只用本产品登录；不要填写其他项目的账户目录。`add-link` 是明确前台执行的同一用例，须 `--browser-dir`，可提供固定 `--idempotency-key`，不会自动重试受阻结果。后台只允许来源时不解析模型秘密、不提取；已有另外获授权的自动提取规则只有在模型后台被显式允许时执行。终端示例还不是三端小白安装器。

来源与处理主人页各显示刷新时的后台快照：`online=true/false/null`、`observed_at`、同步/模型两种运行权限；不返回PID、运行标识或私有目录。只检查当前受控内核运行锁，不根据锁文件残留判断在线，也不猜测后台响应或处理进度。旧版本没有权限记录时返回未知。无法重新确认时不沿用旧在线结论，页面快照30秒后明确过期；不会自动执行、接管或重启。只读AI工具与页面会话无新增管理权限。

本人证明独立于后台快照：有效期15分钟，只证明当时正常账号响应，不代表此刻仍登录。账号变化/失败会使原夹选择失效；列表末页不保证观察期间平台没有变化。当前开发CLI可用 `collection-context --workspace <新库> connect-douyin --browser-dir <本产品独立库外浏览器目录>` 主动开窗口；随后 `collection-context --workspace <新库> discover-collections --browser-dir <同一目录> --headed` 观察收藏夹，`connection-snapshot` 只读本地证明。平台验证需要用户本人参与，不自动导入旧项目登录；发现契约仍需真实兼容核对。网页刷新仅读取已有证明，不能替代登录或发现；小白无终端流程尚未完成。

### 模型配置的新增主人动作

| 动作 | 字段 | 行为 |
| --- | --- | --- |
| `models` | 无 | 返回三个角色的非密钥配置和登记状态，不返回凭据引用、私有目录或密钥；登记不代表能力验证 |
| `model-save` | `role/base_url/model/protocol/parameters/timeout/api_key/expected_profile_id/credential_confirmed` | 主人会话/CSRF、服务器显式启用及确认均必需；旧页面配置发生冲突则拒绝，任务保留不可变模型版本 |

启动时需同时提供 `--allow-model-config` 与 `--credential-dir`；只提供一个拒绝启动，目录不能位于资料库内部或包含资料库。例：

```bash
collection-context-web --workspace ./collection-workspace --allow-model-config --credential-dir ./collection-private-credentials
```

这两个固定目录互相独立，网页不能提交任意凭据路径。仍须用 `--ui --manage` 创建主人口令，默认AI三工具和只读页面无新增权限。空密钥仅在已有角色配置时表示保留原密钥；修改默认配置不更改已排队任务。新密钥输入提交或刷新/退出后清空，不存入浏览器持久存储。

凭据后端由本机启动者指定，页面／AI／任务不能选择后端或路径。上述未加参数的服务示例仍是权限受限的库外私有文件（目录700、文件600），**没有加密**；用于无桌面服务，不能称作系统钥匙串。Mac 桌面候选默认改为系统钥匙串，磁盘只保存确认元数据与受控引用；系统锁定、拒绝或不可用时失败，不回退明文。需要在 CLI／HTTP 服务中显式使用系统后端时，两端都选择同一目录与 `--credential-backend system`，例如：

```bash
collection-context-web --workspace ./collection-workspace --allow-model-config --credential-dir ./collection-system-credentials --credential-backend system
collection-context --workspace ./collection-workspace worker --credential-dir ./collection-system-credentials --credential-backend system --allow-model-calls --once
```

当前系统后端仅实现 macOS；Windows/Linux 指定 `system` 会明确拒绝，不代表这两端发行已完成。目录不兼容时拒绝，不自动导入旧文件或其他项目 Key；文件后端也拒绝把系统元数据当成密钥。现有文件配置与旧任务保留，系统目录与旧目录独立，新默认值轮换不会撤销旧任务所需凭据。提交失败只清理能证明未被配置引用的本次新密钥；结果不明确时保留并报告未知，不自动重试。已确认系统项仅按准确产品命名空间／引用访问，不枚举钥匙串、自动解锁或自动授权。真实验证范围见实施记录；自动撤销、遗留凭据清理、跨机秘密恢复及三端系统凭据仍待完成。

## 5. 远程边界

远程监听需要同时显式 `--remote`、HTTPS 外部地址、TLS 证书和私钥；缺一拒绝。当前未部署到公网、未开放任何现有服务器端口，也未完成真实远程 AI 链路。

服务器不信任代理转发头，不因为收到 X-Forwarded-Host/Proto 就放行。反向代理托管、证书续期、请求日志脱敏和真实客户端仍需后续验收；此版本不提供未经验证的代理跳过参数。默认回环模式不受此后续工作影响。
