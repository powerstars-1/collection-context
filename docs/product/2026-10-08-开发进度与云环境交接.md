## 4. 云开发最小环境

Python >= 3.12，建议 Node >= 22，npm。不要安装根 `backend/pyproject.toml` 以启动旧 `content-agent`；新版源码开发用 `PYTHONPATH=backend/src`，独立发行元数据在 `backend/distribution/pyproject.toml`，它由打包脚本装配源目录。

从仓库根执行：

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r backend/requirements-dev.txt
npm ci --prefix frontend
npm ci --prefix backend/model-runtime
npm test --prefix frontend
npm run build --prefix frontend
```

核心回归（无真实账号、无付费模型）：

```sh
cd backend
python -m pytest -q tests/test_context_service.py tests/test_context_source_management.py tests/test_context_synchronization.py tests/test_context_local_ui.py tests/test_context_branch_reuse.py tests/test_context_extraction_review.py tests/test_context_download_limits.py tests/test_context_login_reconnect.py tests/test_context_pi_client.py
cd ..
```

首次创建原创阅读样例页面（运行目录必须是新目录；重复使用已存在的目录会拒绝初始化）：

```sh
PYTHONPATH=backend/src python backend/tools/library_experience_fixture.py --run data/cloud-reading-001 --port 8832
```

本机入口 `http://localhost:8832/#library`。只放原创合成内容，无同步/模型请求。云 IDE 的预览必须维持正确 Origin 和私有访问边界；如果转发地址不匹配，不删除后端来源校验来绕过，先报告具体环境。不自动监听公网。

空产品库启动（需要验证真实功能时也只用测试配置）：

```sh
PYTHONPATH=backend/src python -m collection_context.launcher --workspace data/cloud-empty-001 --initialize-empty --no-browser --port 8790
```

已有库重启去掉 `--initialize-empty`。FFmpeg、浏览器、OCR 不属于页面/普通离线回归的必需依赖；相关实际测试需要独立安装并验收，不能把跳过写成通过。

Pi worker 的已构建文件随源码保留；更新 SDK 时：

```sh
npm ci --prefix backend/model-runtime
node backend/model-runtime/build.mjs
```

不要手工修改 `backend/src/collection_context/processing/pi_worker.mjs` 或 `interfaces/assets/app.*`。前者需要 Node 22+ 运行；保留 SDK 与传递依赖许可说明。
