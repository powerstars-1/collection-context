# 收藏上下文：并行启动器交付说明

日期：2026-10-01
状态：开发候选；只验证当前 Mac 开发环境，未宣称 Windows、Linux x64 或正式桌面安装包已经通过。

## 交付范围

本批新增独立命令 `collection-context-launch`，用于启动现有轻量管理页。它只监听 `127.0.0.1`，复用统一后端、访问规则和资料库，不启动来源同步后台，不调用模型，也不安装浏览器、FFmpeg、OCR、常驻服务或模型权重。

启动器不迁移、不复制、不删除原资料库。不存在或空目录必须显式增加 `--initialize-empty`；非空且无法识别的目录会拒绝处理。首次创建管理身份时，随机产品口令只在用户自己的终端显示一次，库内只保存摘要；口令不接受命令参数，也不应粘贴到聊天、日志或仓库。

## 安装与启动

发行候选安装管理页所需依赖：

```bash
python -m pip install 'collection-context[launcher]'
```

首次使用默认产品目录：

```bash
collection-context-launch --initialize-empty
```

使用已经初始化的产品资料库：

```bash
collection-context-launch --workspace "/你的/资料库"
```

如果目标目录为空，必须明确确认：

```bash
collection-context-launch --workspace "/你的/空目录" --initialize-empty
```

无桌面 Linux 或不希望自动打开浏览器时：

```bash
collection-context-launch --workspace "/srv/collection-context" --no-browser
```

服务仍只监听服务器自身的 `127.0.0.1`。本命令没有开放公网，也不替代已经设计的 TLS 远程入口。需要远程访问时，应继续使用显式 TLS/认证方案；本批未部署或验收该链路。

停止时按 `Ctrl+C`。服务会有序退出，资料库留在原路径；本批不会安装 systemd、launchd 或其他常驻任务。

## 只读诊断

```bash
collection-context-launch --workspace "/你的/资料库" --diagnose
```

诊断检查 Python、管理页依赖、回环端口、来源浏览器、FFmpeg 和本地 OCR。它不创建资料库、不下载任何内容，也不读取或显示模型 Key、平台 Cookie、正文或产品口令。依赖“已安装”与来源/模型“已授权”分开报告；可选依赖存在不会自动获得执行权限。

来源连接需要用户之后明确安装 `browser` 依赖并单独安装 Playwright Chromium。视频处理需要 FFmpeg；本地 OCR 需要 `ocr` 依赖。启动器只提示缺口，不代替用户下载。

## 验收边界与回滚

- 已覆盖：空库显式门禁、非空目录保留、首次产品口令只显示一次、回环端口冲突、脱敏依赖报告、管理页启动与有序退出。
- 未覆盖：正式 PyInstaller 包、签名/公证、Windows 实机、Linux x64 实机、浏览器首次下载、系统服务安装、真实抖音登录、真实模型调用和付费质量。
- 当前 Mac 验证不能外推为三端完成；Linux 无桌面只补充了同一 Python 入口，未自行部署。
- 回滚只需停止服务并卸载本候选包。资料库不会随卸载删除；若是本批新建且用户确认不要，另行人工处理，启动器本身不提供删除命令。
