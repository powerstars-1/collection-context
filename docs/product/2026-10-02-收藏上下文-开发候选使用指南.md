# 收藏上下文：开发候选使用指南

核对日期：2026-10-02。面向第一次使用本产品的人。

这份指南对应当前统一后端和 Creator 管理页，不适用于旧自媒体控制台。它教你把抖音资料保存到自己的电脑，再让自己的 AI 搜索和读取。收藏、喜欢只作为兴趣线索，不自动代表你的观点或已经掌握的知识。

## 先看当前能用到哪一步

当前仍是开发候选，没有正式公开安装发行。本轮新冻结候选标识为 `ry9qvepc`，包含当前 AI 接入页和最近选库记忆。收到其他候选时，先核对版本；不要照着本指南补装来路不明的依赖。

| 部分 | 当前状态与边界 |
| --- | --- |
| Mac 控制台候选 | 已完成真实 CLI、stdio MCP、认证 HTTP，以及产品库和旧库的终端启动验证；不代表每个 AI 宿主都已接通。 |
| Mac 桌面窗口 | 冻结 `.app` 已通过原生键盘的旧库模式联动、空库取消、首次口令关闭撤销，以及已有原创库启动/停止/退出/重开；登录后的完整使用仍未验收，也未完成签名、公证。 |
| 最近选库记忆 | 新冻结候选已实际验证普通库位置与端口恢复，初始化和四项能力保持关闭。只记成功启动的位置、端口、是否旧库只读；旧库模式恢复仍需单独 GUI 验收。不是自动启动。 |

没有收到对应系统的完整候选包时，请先索取候选包与验收说明。不要自行关闭系统安全功能、移除安全标记或绕过拦截；出现系统阻止打开的提示，保存提示并反馈。当前也不能假定在公开软件仓库输入一条安装命令就能获得本产品。

## 1. 准备一个资料库位置

资料库是普通文件目录，由你选择保存位置。请选择可长期访问的本机磁盘；外置盘要先连接好，使用期间不要拔出或移动目录。不要选系统目录、整个用户目录、云盘占位目录或指向其他位置的链接目录。

有三种情况：

| 你的情况 | 在启动窗口怎么选 |
| --- | --- |
| 第一次使用，没有产品库 | 点击「选资料库」，选择一个新目录或空目录，勾选「同意建立新的空资料库（不覆盖非空目录）」。 |
| 已经用本产品创建过库 | 选择原产品库；不再勾选建立新库，也不勾旧库模式。 |
| 已有本项目旧格式的 Markdown / Obsidian 抖音资料 | 选择旧库目录，勾选「只读连接已有 Markdown / Obsidian 旧库（不复制、不迁移）」。 |

旧库只读只识别已有的旧抖音布局，例如所选库内有 `00_素材收件箱/抖音`，相关文字附件位于 `80_附件/抖音`。也可以选择包含该 `content-vault` 的项目根目录。**它不是任意 Markdown 文件夹的通用导入器。** 不能识别时，不要改用“建立新库”覆盖它。

旧库文件留在原位；产品仅在库外的本机产品数据目录建立访问配置。旧库模式不迁移、不修改、不下载、不请求模型，页面也不提供同步、模型设置和管理操作。

未手动选位置时，程序按操作系统的用户数据目录给出默认建议：

| 系统 | 默认位置规则，仅解释目录，不代表该系统已交付 |
| --- | --- |
| macOS | `<用户目录>/Library/Application Support/CollectionContext/workspace` |
| Windows | `<LOCALAPPDATA>/CollectionContext/workspace`；通常在用户目录的 `AppData/Local` 下。 |
| Linux | `<XDG_DATA_HOME>/collection-context/workspace`；未设置时在用户目录的 `.local/share` 下。 |

尖括号内容都是占位说明，不要原样创建这样的目录，也不要照搬他人电脑路径。

## 2. Mac 首次打开：先完成只读启动

1. 保留收到的完整候选目录。若目录中同时有 `CollectionContextDesktop.app` 和 `CollectionContext` 控制台目录，先不要拆散或只移动其中一个；AI 接入可能需要配套控制台程序。
2. 打开 `CollectionContextDesktop.app`。本阶段仍需验收冻结应用的完整交互；如果窗口打不开或被系统阻止，停在这里反馈，不通过关闭系统保护强行继续。
3. 在「收藏上下文 · 本机启动」窗口选择第 1 节对应的库模式，核对「本机端口」（默认 `8787`）。
4. 第一次先不勾下面四项能力；只读查看已有资料不需要配置模型或登录抖音。新空库里暂时没有资料，这是正常结果。
5. 点击「启动并打开管理页」。这个按钮会先检查当前目录、依赖和端口，再请求你的明确确认。选择目录本身不会启动或导入。
6. 如果是新空库，核对「建立空资料库」确认框；如果是旧库，核对「只读连接旧库」确认框。选错位置时取消，重新选择。
7. 首次建立访问权限时，会出现「保存本机管理口令」窗口。自行保存一次性显示的口令，再勾「我已自行保存这个口令」，点「已保存，继续」。点「取消（撤销本次新权限）」或关闭这一步，会撤销此次新建权限，不继续启动。
8. 浏览器打开「连接你的收藏库」后，将刚保存的口令填入「产品访问口令」，点「进入收藏库」。不要填抖音密码或模型 API Key。

「复制口令到本机剪贴板」只在你点击后复制；剪贴板可能被其他软件或跨设备同步读取。建议粘到自己的密码管理工具；复制完成不等于已经妥善保存。不要将口令发到聊天、截图、公开问题单或仓库。

看到「管理页已就绪；请在本机浏览器登录。」才表示服务已经就绪。浏览器没有自动打开时，使用启动界面或终端实际显示的本机地址；改过端口就使用新端口。其他电脑的 `127.0.0.1` 指向其他电脑自己，不能直接用它访问这台电脑。

若没有桌面窗口，但开发者已经提供同版控制台候选和启动协助，可以请开发者使用其 `launch` 入口；需要显式指定当前库，旧库另加 `--legacy-vault`。不要把开发环境的 Python 路径或旧项目命令当成普通用户的安装步骤。

## 3. 看懂管理页

顶部有四个入口：

| 入口 | 做什么 |
| --- | --- |
| 收藏库 | 按喜欢、收藏、收藏夹、博主作品、单条链接筛选；搜索并逐项阅读证据。 |
| 同步与处理 → 添加与来源 | 独立登录、登记一条作品或一个来源范围、手动同步或定时同步。 |
| 同步与处理 → 任务与处理 | 查看任务、选择历史提取、设置新增自动提取和调用上限。 |
| 设置 → 模型与接口 | 分别配置音频转写、画面与图片、内容总结。 |
| AI 接入 → 接入说明 | 获取当前库、当前程序位置对应的 MCP 配置、CLI 参数和 HTTP 说明。 |

窄窗口可能只显示顶部图标，可根据图标提示识别入口。顶部「主人管理会话」与「只读会话」表示权限不同；旧库会显示「旧资料库 · 只读浏览」。

## 4. 需要同步或识别时，再开启对应能力

在桌面启动窗口点击「停止」，等服务实际停止后，再重新选择能力并启动。页面不会替你偷偷打开这些权限。

| 启动窗口选项 | 允许做什么 | 不等于什么 |
| --- | --- | --- |
| 允许配置模型 | 保存你提供的模型配置，优先使用系统凭据库。 | 保存不验证 Key 或模型，也不直接请求模型。 |
| 允许在独立浏览器登录抖音 | 在产品自己的浏览器中完成登录或验证。 | 登录不等于同步作品。 |
| 执行已确认的模型任务 | 运行本库已确认的排队模型任务；需要同时允许配置模型。 | 不是无费用测试；可能上传媒体并计费。 |
| 执行已确认的来源任务 | 运行本库已确认的排队来源任务；需要同时允许抖音登录。 | 不是自动授权所有喜欢、收藏或历史作品。 |

启动执行能力前，先查看之前是否留下已确认的任务。重新开启执行器可能处理这些任务，不只是从你现在点击的那一条开始。

### 组件要按需安装

停止当前服务后，点「安装运行组件」，在「固定产品清单 · 不自动下载」里核对可用项、来源、许可和体积，再选择一项并点「确认所选单项安装」。默认不选任何项；每次只确认一个组件。

- 来源浏览器用于独立平台登录；视频/音频工具用于准备音轨和画面；本地 OCR 运行库与权重用于本机文字识别。
- 候选包可能随包携带某些组件。清单显示「随包携带，无网络下载」时，其来源地址只是上游出处；不要把它当下载地址自行替换。
- 清单显示本机不支持、运行库不匹配或「此程序未携带该组件」时，先获取匹配的完整包，不手工改组件清单。
- 安装成功只是静态校验通过；不代表浏览器已经登录、真实媒体已经解码或识别精度达标。安装不会打开上述四项权限。
- 纯阅读已有文字不要求安装浏览器或 OCR。取消安装后要等真实安装线程结束，不能仅凭点过取消就认为已停止。

## 5. 配置自己的模型

进入「设置 → 模型与接口」。三个角色独立配置，可以使用同一个供应商，也可以不同：

| 角色 | 必须支持的能力 | 页面请求协议 |
| --- | --- | --- |
| 音频转写 | 真正接收音频输入并转写或理解音频。普通文字聊天、支持看图片，都不能证明它支持音频。 | 「聊天接口接收音频」或「音频转写接口」，按供应商实际接口选。 |
| 画面与图片 | 图片输入；接受本产品准备的画面或图片。 | 「兼容聊天接口」。 |
| 内容总结 | 文字输入与总结。 | 「兼容聊天接口」。 |

每个角色分别填写「兼容接口基础地址（通常含 /v1）」「模型名」「请求协议」「API Key」。这里填供应商或自己网关提供的客户端基础地址，不填管理后台页面地址；不要把别的软件的渠道地址填写习惯照搬过来。

第一次先保留可选参数的空对象；只有确认供应商支持时才在「超时与可选参数」中设置。参数填写错误不会变成“自动换模型”。确认接口可信后，点击「保存音频转写」「保存画面与图片」或「保存内容总结」。已有角色的 Key 留空可保留原密钥。

页面出现「已登记 · 尚未验证模型能力」是配置状态，不是测试成功。保存、刷新、退出后，密钥输入会清空且不回显。Mac 桌面入口使用系统凭据库；不可用时不会悄悄改成明文存储。

修改默认模型不改变已登记任务的固定配置，旧任务所需凭据也不会因此自动撤销。要测试新配置，应新建一次明确授权的小范围任务，不连续重试旧任务。

## 6. 独立登录抖音，然后先保存一条作品

前提：普通产品库；来源浏览器组件可用；启动时已允许独立登录。首次请在后台所在的电脑上操作，不在另一台设备等登录窗口出现。

1. 进入「同步与处理 → 添加与来源」，找到「本人账号与收藏夹」。
2. 勾选「允许本次独立浏览器访问本人账号页面；不获取作品、不调用模型」，点击「打开独立登录」。
3. 在打开的产品独立浏览器里，由你完成平台要求。它不会自动借用日常浏览器或其他项目的登录配置。
4. 返回管理页核对本次连接观察的结果。以后已有独立登录时可点「验证已有登录」；「刷新本地连接」只读取本地状态，不等于重新向平台验证。账号及收藏夹观察有时效，过期后要重新验证。
5. 如果需要取消，点「取消本次验证」。仅离开页面不会取消已确认的验证任务。

先试单条作品：

1. 在「添加一条抖音作品」粘贴你有权处理的 `<作品链接或分享文字>`。
2. 只看文字来源时不勾下载；需要后续音频、画面提取时，勾选「下载并准备原媒体；不请求模型」。
3. 勾选「确认仅访问此作品及上述下载范围」，点「登记单条任务」。
4. 确认后台已开启「执行已确认的来源任务」，再点「刷新本条任务」或到「任务与处理」查看状态。
5. 成功后在收藏库打开已保存资料。若提示原文保留、媒体尚未完整准备，先核对原因；不能直接当成已完成转写。

这一步本身不请求提取模型。但如果你之前另行开启了新增自动提取，它可能按原来确认的规则接着处理。第一次验证建议先把新增自动提取保持关闭。

真实账号遇到登录要求、风控或内容不可访问时，本候选不保证能继续取得资料；不要用无限重试或替换别的项目 Cookie 解决。

## 7. 从单条扩大到喜欢、收藏、收藏夹、博主

仍在「添加与来源」：

- 「喜欢与收藏」：选择本人列表「喜欢」或「收藏」，设置每批最多作品数，确认范围后点「保存本人范围」。
- 「指定收藏夹」：先通过「发现收藏夹」取得本次可选项，选定收藏夹后点「保存收藏夹范围」。没有观察到的收藏夹不能凭名称猜一个。
- 「博主已发布作品」：填 `<博主完整主页链接>`，设置范围，点「保存博主范围」。这是指定博主的作品，不是他的喜欢列表。

目前每批输入范围是 1～20 条，页面默认 5 条。第一次可手动改为 1～2 条；保存范围只是登记，没有立即同步。到「已登记同步范围」点击该范围的「同步一次」，再确认本次范围。

需要定时同步时，填「间隔（分钟）」并点「启用定时」。当前间隔范围是 60～1440 分钟；电脑、产品服务和已授权后台执行器必须保持运行。休眠后不承诺补跑所有错过的批次。暂停用「暂停定时」；它不取消独立手动任务，也不撤回已经发出的访问。

列表中的“每批最多”是上限，不保证每次新增这么多，也不代表已取完全部历史。已保存作品会去重并保留来源关系；不知道真实点赞时间时，不会用首次发现时间冒充。

## 8. 手动提取和自动提取怎么选

第一次建议先手动处理一条自己有权上传的短样例，核对音频、画面、总结后再自动化。云端模型由你提供，费用由供应商或你的网关收取；本产品不赠送模型额度。

### 手动处理已有媒体

1. 确认三个角色已配置，来源任务已经把媒体准备好。
2. 进入「任务与处理 → 选择历史资料」，选择一条。这里仅列已准备媒体的资料，一批最多 20 条。
3. 填「每条最多云请求次数」。页面会显示本批请求总上限，**它不是价格或金额上限**。
4. 核对「确认所选媒体上传及调用上限；金额未知」后，点「提交所选历史批次」。
5. 后台已开启「执行已确认的模型任务」时才能执行。未开启会排队；无需反复提交。
6. 在「已登记任务」点「刷新状态」，查看阶段结果和请求记录，再去收藏库核对证据。

默认填写的 `2` 次只是当前表单值，不保证足够完成音频、多张画面和总结。一个视频可能被拆成多个音频片段、多个画面请求，再做总结。先确认要处理的样例和可接受上限；不足时如实停止或部分完成，不代表原作品没有更多内容，也不要为了消除报错直接填极大值。

### 后续自动处理新增资料

在「自动运行」中选择「新增资料自动提取」开启，分别填写「每条最多云请求次数」「本次最多新增任务」，确认上传媒体和调用上限，再点「保存自动规则」。

这与来源定时同步是两个独立开关：定时同步负责找作品，自动提取负责处理合条件的新增资料。保存自动规则不会授权所有历史资料，也不等于后台已经在线。

关闭再重开自动规则，不应假定所有旧积压都重新获准。旧自动任务需要恢复时，页面可能提供「预览恢复」；先核对原固定模型和请求上限，再决定是否确认。

### 状态要这样理解

| 页面状态 | 应该做什么 |
| --- | --- |
| 已排队 | 查看后台执行器及本次能力是否开启；不要重复提交。 |
| 运行中 | 刷新核对阶段和请求数；在线快照不保证一直有进度。 |
| 完成 | 继续核对正文、转写、画面文字；不代表信息百分之百准确。 |
| 部分完成 | 查看哪些内容已经保存、哪个阶段缺失，保留已有成果。 |
| 失败 / 需人工处理 | 记录页面的原因标签，先处理配置、登录、媒体或费用不确定性；不会自动无限重试。 |
| 已取消 | 后续处理停止；已经保存的内容和已发出的请求可能仍保留或计费。 |

「取消后续处理」不是撤销账单。页面中的「结果不明」和「已完成但无用量」不能按零费用理解；需要结合供应商用量记录判断。产品未取得金额时会写金额未知，不用猜测价格填补。

## 9. 看正文、缺口和原始证据

进入「收藏库」，用标题、作者或已提取文字里的 1～3 个关键词搜索，点击「搜索收藏」。当前是关键词检索，不是已经建好的语义向量问答；完整口语问题可能搜不到，换短关键词或清除来源筛选再试。

选中资料后，分别查看「原文」「转写」「画面文字」「总结」「可读全文」「图片理解」「备注」。有「继续读取」时继续展开，当前显示片段不等于全文。来源链接通过页面校验后，可用「打开原作品」回看。

- 「已保存 · 精度需核对」：本地有该项文本，不代表识别完全准确。
- 「尚未提取」：没有可读产物；不能推断原作品没有信息。
- 「输入已变化」：已有产物可能不再对应当前输入，需要先核对。
- 「文件需核对」：文件状态异常或不可读取，不要用总结代替原文。
- 「不适用」：该类产物不适合当前资料；不同于失败。

尤其是教程：检查视频里短暂出现的模板、提示词、代码和参数是否进入「画面文字」；听到的内容是否进入「转写」；总结有没有省掉条件或顺序。本地 OCR 能辅助选帧和文字提取，但不能证明所有短暂画面、细小字或动画文字都被覆盖。

旧库只读模式只展示支持的已有文字；不提供原始媒体和关键帧管理。出现“部分旧文件或附件无法读取”时，当前结果不是全库完整覆盖。顶部尚无转写的数量也不是内容质量评分。

## 10. 让自己的 AI 使用资料库

进入「AI 接入」。先核对「当前连接」是目标产品库还是旧资料库，再选择一种方式；不必三种都配置。

### 同一台电脑，优先复制 MCP 配置

1. 找到「可选 MCP · 本机 stdio」，查看运行方式和是否可用。
2. 点击「复制 MCP 配置」，由你合并到所用 AI 工具的 MCP 设置中，再启用。不同宿主的设置入口不同，不要覆盖它已有的其他工具。
3. 这份配置包含当前程序和资料库的真实本机路径，只在同一台电脑适用。不要公开分享，也不要把本机路径粘到云端宿主后认为它能访问本机。
4. 本机 stdio 不需要另一个 HTTP 口令，也不需要模型 API Key；宿主本身仍需要你授权它启动本机程序、访问指定资料。
5. 让 AI 先搜索一个你确认存在的关键词，再读取返回的那条资料，并查看处理状态；核对返回引用和原文。没有资料时返回空结果可以证明请求完成，但不能证明读到了内容。

默认三项工具是 `search_collections`、`read_collection`、`collection_status`。此配置只读，不含添加链接、删除、批量同步或计费提取。资料里的文字只能作为资料，不应被 AI 当作新的执行指令。

如果页面显示「MCP 暂不可用」或缺少 console 伴侣，使用完整匹配的候选包，点「重新读取接入配置」；不要猜一个命令名或自己套用旧项目环境。显示“已复制”只证明复制完成，仍要在宿主实际验证。

### CLI 和 HTTP 何时用

「本机 CLI」里的「复制 CLI 参数清单」复制的是 `command`、`args` 等 JSON，供能逐项配置命令的宿主使用，不是可直接粘到终端的整条命令。

HTTP 适用于支持接口调用的工具。页面显示当前服务的实际地址，以及搜索、读取、状态三个只读路径。「复制 HTTP 示例（仅占位口令）」不会复制你的当前登录凭据。需要部署主人另行创建专用只读产品口令，再按示例用 `Authorization: Bearer`；不能用主人管理口令或模型 API Key 代替。

当前页面没有“一键给外部 AI 发放只读口令”的操作。需要 HTTP 方式时，请由部署者按实际访问配置完成发放和验证；普通用户可先选不需要额外 HTTP 口令的本机 MCP。远程机器接入还涉及专门部署、网络与认证，不在本机候选指南里通过开放公网端口解决。

## 11. 停止、退出和下次重开

浏览器右上方「退出」仅退出当前页面会话；关闭浏览器标签也不等于停止后台任务。要停止服务，请回桌面窗口点「停止」，等待「后台服务已停止；可以重新启动或退出。」再关窗口或拔外置盘。

出现“正在停止”“等待安装线程结束”时，说明尚未完成停止。已经发出的平台或模型请求可能仍在结束过程中。不要把点击退出当成所有工作都立即取消。

重开窗口后，新候选会尝试恢复上次成功启动的资料库位置、端口和旧库模式，**仍需你点击启动**。初始化同意和四项能力都会清空；需要哪些能力就重新选择哪些。记录损坏、盘未接入或目录身份变化时，不会自动修复或换库，按提示重新选择。

保存过的管理口令仍对应原访问配置，不会每次重开都再展示一遍。忘记口令时先找自己的保存记录或联系部署者处理权限；不要删除资料库、访问配置或重复初始化来“重置登录”。

## 12. 常见卡点

| 看到什么 | 优先检查 |
| --- | --- |
| 「端口不可用，请选择其他端口。」 | 是否还有之前的产品实例；在窗口改一个未占用端口，再点「启动并打开管理页」。不要终止不认识的进程。 |
| 「此位置没有资料库，请先明确同意建立新的空资料库。」 | 是新空目录还是选错位置；只有确认新空库时才勾建立。 |
| 「目录不可用，或含有未识别的资料」 | 不要覆盖。旧格式请用旧库模式；普通文档目录不自动导入。 |
| 「未识别到可用的抖音旧库，或旧库身份已变化」 | 核对旧布局、磁盘与目录位置；不要初始化、复制或移动文件来强行通过。 |
| 目录检测一直等待 | 系统是否在等待目录访问授权，外置盘是否在线。可停止本次启动；不要在等待期间自动安装组件。 |
| 「启动依赖未就绪」或组件不可选 | 保存当前错误标签，索取匹配的完整候选。发现一个模块不等于其实际功能已可用。 |
| 模型表单无法填写 | 本次是否开启「允许配置模型」，当前是否主人会话；旧库模式本来不可配置。 |
| 登录按钮不可用或一直等待 | 来源浏览器、独立登录权限和实际后台所在电脑；不要假定日常浏览器已经登录就有效。 |
| 登记后一直「已排队」 | 执行器是否在线，以及对应模型/来源执行能力是否开启；不要反复点提交。 |
| 模型拒绝音频或返回格式错误 | 核对音频角色和协议。视觉模型可看图不代表能听音频，保存配置也未进行实际能力测试。 |
| AI 接入配置读取失败 | 后台是否运行、登录是否有效、前后端是否同版；处理后点「重新读取接入配置」。 |
| 搜索为空、某项没有正文 | 去掉过细筛选，用原文关键词；核对资料是否已入库、媒体是否已提取、是否有「继续读取」。查不到不能证明原内容不存在。 |

反馈问题时提供：候选标识、系统和芯片类型、选择的新库/旧库模式、在哪个按钮后出现、页面错误标签。截图先遮住用户名路径、来源账号、内容、口令和密钥。不要发送整个个人资料库或登录目录。
