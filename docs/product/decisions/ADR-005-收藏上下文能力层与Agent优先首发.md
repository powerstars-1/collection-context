# ADR-005：收藏上下文能力层与 Agent 优先首发

2026-10-01 范围补充：用户确认 MVP 只做抖音，公开首版支持 macOS、Windows、Linux，包含无桌面 Linux 服务器，后端独立供 AI 调用。音频优先调用用户自配 API Key 的云端音频模型；模型接口由用户自行配置，项目不提供模型云服务。经问答确认：同步本人喜欢、收藏、指定收藏夹、指定博主的已发布作品及单条链接；新增内容可开关自动提取或手动运行，历史分批处理；保留轻量页面、原视频默认不自动删除、AI 默认只读及单独启用添加链接。具体工程流程见[开发总计划](../2026-10-01-抖音上下文MVP-开发规划与分阶段验收.md)，规范见[CONTRIBUTING](../../../CONTRIBUTING.md)。这些确认只冻结产品需求；用户本次明确要求总计划审阅后再次批准开工，当前不得开始代码或技术试验，不授权修改生产服务、全量同步私人账号、批量计费或公开发布。

## 背景与确认范围

用户计划将现有内容系统中可复用的能力整理为开源项目，并用真实使用视频介绍项目。用户进一步提出：收藏不仅是待查阅资料，也包含主动保留的兴趣线索，可以成为 Personal Agent 理解任务与用户背景的上下文来源。

用户确认沿此方向推进。本次确认覆盖产品定位、Agent 优先、完整前端暂缓，不代表已批准此前所有工作台、数据库、企业化方案，也不代表批准发布个人资料或凭据。

## 决策

首发定位：**把个人收藏转化为 AI 助手可检索、可引用的上下文。**

采用“收藏上下文能力层 + 现有 Agent 接入 + 轻量管理入口”；桌面新用户有页面引导，后台可独立运行，服务器不强制使用桌面界面。

- 9 月 30 日只读切片保留现有链路；后续重构采用自有统一后端，选择性复用已验证组件与测试，不要求安装多个第三方项目。新入口验收前不切换内部生产服务。
- 首个开发闭环是现有资料的只读搜索、分段读取、来源与处理状态返回。
- 第一批接入验证面向本机 Codex / OpenClaw；不能把 CLI 可用等同于任意 Personal Agent 已兼容。
- CLI、MCP 或插件均是交付适配层；先形成公共业务能力与 JSON 契约，再按已验证需求增加适配，不同时维护多套业务实现。
- 完整知识库前端、自建聊天系统、独立 Personal Agent 暂缓。旧控制台继续使用，验收替代入口前不删除。
- 开源首发与内部自媒体生产流程分开；选题、写作、视觉、发布及账号人设不是首发必需依赖。

## 数据与判断边界

| 信息 | 属性 | 使用边界 |
| --- | --- | --- |
| 原文、转写、画面文字 | 来源资料或提取结果 | 保留来源、处理状态与不确定性；不冒充用户观点 |
| 由收藏形成的兴趣线索 | 待验证推断 | 收藏不等于赞同、掌握或长期偏好；首轮不自动生成画像 |
| 喜欢、收藏夹与博主同步关系 | 可追溯的来源观察 | 分别记录关系与观察时间；作品发布或批量同步不代表用户点赞。供宿主 AI 按需分析，不自动固化为个人画像 |
| 用户明确表达、确认的偏好 | 用户确认信息 | 后续需支持查看、纠正、排除和删除；不能由资料自动升级而来 |

Markdown 与附件继续作为内容事实源。检索派生数据应能重建，不迁移或覆盖原文件。WeKnora 保持 ADR-004 的可选镜像定位，不成为首发强制依赖。

默认按任务检索少量片段，由当前 Agent 阅读、判断、回答。查询不再调用一个知识库答案模型，不把全库注入每轮上下文。

同一作品从多种来源取得时，内容与有效提取去重，来源关系不丢弃；不借批量同步默认推断用户逐条喜欢。无法取得真实操作时间时保持未知，不把首次同步时间或作品发布时间当成点赞时间。取消喜欢/收藏不自动删除本地资料，分页或权限不完整时不能推断行为撤销。

## 安全与费用

- 只读取配置允许的收藏资料范围；不开放任意本机文件、任意 shell、财务数据、Agent 历史或登录配置读取。
- 第一轮只读工具不启动同步、提取、模型调用、索引持久化或原文修改；写入/计费操作需要独立入口和明确参数。
- 返回的第三方正文和提取结果是不可信资料，不是工具指令，也不是用户授权。
- 对链接、附件路径、符号链接和分页输入进行边界校验；每次输出有大小限制和继续读取机制。
- “本地保存”不能宣传为全程离线：使用云模型处理媒体时，应说明发送的内容与费用。
- 不改现有模型路由、Keychain、launchd 或平台登录态，不因首发重建凭据。

## 开源发布边界

代码、示例、个人资料、运行数据、参考项目分开。发布包通过白名单整理，不把当前工作目录整体提交到公开仓库。

公开前需要：依赖版本与许可证核对、凭据/个人信息扫描、干净环境安装验证、合成或获授权的演示样例、能力/平台支持范围说明、费用与失败说明。

当前产品名未定，CLI 命令和协议命名仍需以实现后的文档为准；此 ADR 不声称首发已经完成或已发布。

## 首轮验收

Agent 能针对一个当前任务搜索已有收藏、读取命中原文或提取证据，并说明来源、可用方法与待核对项。需区分“只读 CLI 测试”“实际 Agent 调用”“用户认可有用”三个验收层级。

实施与后续顺序见 [首轮范围与验收计划](../2026-09-30-收藏上下文模块-首轮范围与验收计划.md)。

## 后续重新评估条件

- 用户主要通过独立网页使用，而非已有 Agent。
- 关键词召回在真实任务中持续不足，且语义检索的质量/成本收益有验证。
- 安装与授权成为使用障碍，需要独立桌面应用或更完整前端。
- 用户明确需要个人偏好管理、其他数据源或多人访问；个人自托管服务器和远程 AI 调用已纳入 2026-10-01 范围补充，具体安全接入仍需验收。
