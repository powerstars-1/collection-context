# 深空视觉质感复评与素材候选

日期：2026-10-07。用户要求重新调研精致的同类案例、查素材来源与可复用性。
本轮交付：设计诊断、案例分析、三张本地素材、下一版建议。没有修改运行界面。

## 证据范围

核对了当前页面的结构信息、上一轮已保存的实际工作台截图，以及当前 space-ui.css。浏览器截图与外部页面交互连续超时，所以本轮的参考判断依据公开案例截图、制作方文章与官方素材页面；没有声称完整操作或实测参考站的动画。

## 当前廉价感的具体来源

以下为设计判断，不是性能测量。

1. 材质过度重复：导航、卡片、按钮都使用蓝灰渐变、亮边、内阴影。小面积上的多重明暗容易像塑料浮雕。
2. 主视觉不足：中心重复线圈缺少体积明暗，六个节点同为网格球。很难通过形态认识模块，容易产生技术演示感。
3. 光照不统一：星点、卡片亮边、中心泛光各自发亮，缺少明确的主光源和前后距离。
4. 内容层级偏弱：小号英文、重复“规划中”和说明在很多位置出现，装饰占据空间，真正应辨认的中文模块名却不突出。
5. 星空只填了背景：控件与场景没有统一的空间关系。继续增加星点并不能自动修复材质与构图问题。

## 最有价值的三个参考

### Igloo Inc / Abeto × Bureaux：主视觉材质与制作方法

[制作方完整案例](https://www.awwwards.com/igloo-inc-case-study.html?ref=webgpu.com)

![Igloo 案例封面，仅供研究](https://assets.awwwards.com/awards/images/2024/09/igloo-coverB.jpg)

作者说明：Bureaux 提供情绪板、渲染图、3D 素材；团队先用灰模和简易镜头预演验证体验，再在浏览器里共同迭代视觉和代码。各项目最初共用冰块，后因太相似改为不同形状。材质与模型使用 Houdini、Blender，界面设计使用 Figma 等工具。

对应本项目：保留已认可的中心与模块布局，但更换粗糙的主视觉表达；每个模块至少有清晰的符号区别。先验证静帧，再给少量部位加运动。

不直接复用其商业模型、贴图、音效或程序；未发现这些资产的开放复用许可。也不为模仿案例把业务文字改成 WebGL。

### Lusion：黑色画面中的焦点和体积

[作品与制作方访谈](https://www.commarts.com/project/36283/lusion) · [Spaace 官方案例](https://lusion.co/projects/spaace/)

![Lusion 官方作品展示截图，仅供研究](https://image.commarts.com/images1/7/1/6/1/1/1161756_102_1160_LTc1NTU1MTUzNi0yOTMyNjI4Mzg.jpg)

观察：黑色画面由主物体、明确的受光面和干净文字建立焦点，视觉并不依靠每个控件都包一圈亮边。制作方访谈明确涉及实时 3D、反射与光照技术；Spaace 案例列出 3D Design 和 WebGL 服务。属于专业定制制作，不能假设存在可直接下载的同款素材包。

对应本项目：中心图形需要有清晰轮廓和内部明暗；背景和节点降低亮度，避免同时争夺注意力。只把有限的精细运动交给中心主体与面板过渡。

### Linear 2026：页头、按钮、列表的精细控制

[官方界面更新解释](https://linear.app/now/behind-the-latest-design-refresh)

作者明确减少导航权重、图标装饰和分隔线，统一页头及操作位置。它不是宇宙风格参考，而是工作区控件的参考。

对应本项目：导航压平、减少背景套框；普通按钮保留可辨边界与点击区域；主按钮只用一个明确的浅色；文字、边框、表面三个层级分开控制。收藏正文和设置仍需适合长时间阅读。

补充候选：

- [NASA Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851/)：提供星空、银河、明亮恒星的独立层及不同分辨率，适合控制远近层次；按单项署名及 [NASA 使用说明](https://www.nasa.gov/nasa-brand-center/images-and-media/)判断用途，不笼统宣称所有 NASA 内容无条件商用。
- [ESO 银河全景](https://www.eso.org/public/images/eso0932a/)：实拍空间素材候选。采用时检查单图标注，遵循 [ESO 许可与完整署名要求](https://www.eso.org/public/copyright/)。尚未下载。

## 建议的下一版

建议方向：黑色、低饱和的天文观测空间。

| 部分 | 调整目标 |
| --- | --- |
| 背景 | 真实星空作远景，银河只在局部形成不均匀的明暗层次；保持大面积黑色 |
| 中心 | 一个主视觉，轮廓明确、光线统一；保留中心的位置和进入模块的结构 |
| 模块 | 保留六个入口，去掉相同网格球造成的重复感；提高名称可读性 |
| 页头 | 扁平、克制，减少嵌套边框；中文标题和当前导航优先 |
| 按钮 | 减少多重渐变与凸起；普通操作有明确边界，主操作亮度突出 |
| 动效 | 延续已认可的克制反馈；背景极轻微运动，面板进入与返回连续对应 |
| 内容页 | 黑色表面与清晰文本为主，星空在阅读区域后显著减弱 |

素材只提供真实纹理，精致感仍需要构图、字号、光线、间距与运动共同完成。下一步先做同一工作台构图下的静态视觉样张，直观看主视觉与控件是否协调，再整合到现有交互。
