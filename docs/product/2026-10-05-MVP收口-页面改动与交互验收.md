## 3. 一条新用户旅程

```text
空库 → 顶部粘贴链接 → 当前条目已保存 → 查看原内容或提取
                                           ↓
                            缺媒体：单条补存 → 提取
                            缺配置：设置模型 → 回到这一条
                                           ↓
                       已有结果先可读；缺口独立重试
                                           ↓
                   总结 / 转写 / 画面 / 自己的备注
                                           ↓
                  搜索找回 → 复制给 AI / CLI 按需读取
```

另一入口是同步本人喜欢、收藏、指定收藏夹、指定博主。它最终落到同一条资料和阅读页，不产生第二套“同步资料”。

## 5. 按钮与状态契约

| 区域/控件 | 点击行为 | 完成/异常衔接 |
| --- | --- | --- |
| 保存链接 | 校验平台链接；去重；创建单条保存任务 | 同条打开已有资料；成功进入该条；不默认强制模型提取 |
| 来源分类 | 筛选同一资料集 | 保留列表/阅读路径；空态可同步此来源或返回全部 |
| 搜索 | 搜索标题、作者、已有正文和备注 | 无结果给清除入口；正式搜索仍以现有词法能力为准，不冒充语义检索 |
| 全部/可阅读/待处理 | 按资料与产物状态过滤 | 部分可读同时可进入可阅读和待处理；不互相排斥 |
| 列表条目 | 右侧打开内容 | 当前项明显选中；返回保留筛选 |
| 专注阅读/退出 | 收起/还原旁栏 | 不丢当前内容、查询和来源 |
| 原作品 | 新页打开已保存来源 | 无地址不造链接 |
| 提取内容 | 展示模型使用及媒体准备摘要，确认本次动作 | 留在当前资料；处理异步进行；可继续浏览 |
| 保存媒体并提取 | 为当前作品补存媒体，再继续提取 | 单条失败单条重试；不全量同步；既有内容不清空 |
| 配置模型后提取 | 进入设置，保留返回条目标识 | 配好回到同一条；需实际校验后才允许付费提交 |
| 补齐未完成内容 | 明确哪些产物缺失、将重跑哪些步骤 | 复用有效音频/画面；未知计费结果不能自动重试 |
| 重试失败步骤 | 只提交选定缺口 | 显示重试范围及可能费用；失败不删除已有结果 |
| 总结/转写/画面/备注 | 切换当前产物 | 不存在即明确缺失，不填假文案；无音轨应显示不适用 |
| 目录与复制这一段 | 定位当前正文，或复制该块 | 不混入整个页面和系统说明 |
| 放大画面 | 查看原帧与真实时间 | 返回相同条目；无帧不造图片；原型只带一个原帧 |
| 保存备注 | 保存当前条目的自己的想法 | 正式实现沿用预期版本校验；原型明确刷新重置 |
| 交给 AI | 带当前条目进入交接页 | 提供可复制材料/来源，返回仍是当前条目 |
| 复制接入说明 | 复用已有安装提示词 | 不猜安装地址，不执行安装，不暴露凭据 |
| 同步范围复选 | 本人喜欢/收藏/收藏夹/博主范围 | 正式产品需选择真实发现的收藏夹或填写博主；原型使用明示的演示范围 |
| 新增自动提取 | 只影响后续新资料 | 关闭时只保存；开启时逐条处理成功入库项，不依赖整个批次成功 |
| 同步选中来源 | 提交所选范围，按钮显示运行态 | 无选中或未连接则禁用并说明；完成后可看结果 |
| 已保存条目列表 | 直接打开此次结果中的具体资料 | 正式实现需要批次 item_refs；当前累计接口不能假装具备批次筛选 |
| 查看未完成/处理这一条 | 展开原因，定位到缺失条目 | 不把用户送去无关设置，不重跑成功部分 |
| 重新连接/退出登录 | 用户自己的平台连接操作 | 登录过期不删除资料；正式浏览器登录另行按现有流程处理 |

## 6. 生产实现顺序与保留项

样稿确认后依次做这三包，不再展开一轮大重构：

1. **体验接线**：在已有 App/Library/Sources/Access 组件中适配连续布局和状态主动作；保留当前导出、隐藏/恢复、平台原文、完整阅读稿、配置、任务查看、备注版本能力。不要用原型模拟 reducer 替换生产应用服务。
2. **补齐两处业务衔接**：单条缺媒体 → 补存 → 提取；批次部分完成 → 对已保存、具备条件的条目提取。检查并利用现有任务/幂等/恢复实现；批次查询缺契约则补最小结果引用。
3. **实体验收**：先跑隔离数据和失败恢复，再用有授权的最小真实样本验证。记录真实模型请求、复用和未完成项；当前原型验收不能替代这里。

本批不迁移 SQLite、不做向量检索、不做内容图谱、不增加内置聊天模型、不重做模型 SDK；已经可用的接口保留。引用/产物版本契约按照总计划 §14 为未来选题池留出扩展点。
