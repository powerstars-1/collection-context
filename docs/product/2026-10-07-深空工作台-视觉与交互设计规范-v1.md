# 深空工作台：视觉与交互设计规范 v1.1

日期：2026-10-07｜状态：v1 灰色球体方向已被用户否决；v1.1 已制作隔离预览，待视觉审阅，未替换正式页面。

配套文件：[优化执行文档](2026-10-07-深空工作台-优化执行文档-v1.md)。本规范定义目标，不代表当前页面已达到这些要求。本次修正同时更新 8818 隔离预览；不修改正式运行页面、业务流程、资料或模型配置。

## 1. 唯一设计方向与范围

方向名：**静默深空 / Quiet Observatory**。

画面由黑色空间、可辨但不抢眼的真实星野、原有流动丝线核心、六个网状节点及连接关系，以及清楚可读的工作界面组成。浅色只集中在文字、当前操作与少量受光边缘。界面材质为哑光；主视觉负责空间感。

保留用户已经认可的工作台入口关系、六模块位置关系、两栏/三栏结构、连续可逆的面板运动，以及收藏→提取→阅读→交给 AI 的能力。作品库、创作台、选题池等未实现模块继续明确标为“规划中”，不能通过视觉升级伪装成功能已经完成。

本次覆盖：启动/断连、全局页头、工作台、收藏列表与画布、阅读详情与展开阅读、同步来源及全部弹窗、内容任务及阶段重试、模型服务、处理设置、资料与用量、AI 接入、提示与异常状态。未来业务能力不在本次范围。

### 1.1 明确停止使用的表现

- 蓝灰金属渐变按钮、多层内阴影、每块组件都有亮边的玻璃浮雕。
- 大片蓝紫星云、彩虹光晕、随机流星、密集闪烁、鼠标拖尾。
- 用实心灰球替换丝线核心，或取消网状节点改成普通后台卡片。原有节点缓慢运动保留，禁止新增整屏闪烁。
- 操作卡片悬停抬起、点击弹跳或明显缩放。
- 功能标题下重复小号英文，或用极小字号换取所谓精致。
- 浅色 Markdown 默认样式混入深色阅读区。
- 普通操作仅剩几个灰字、图标和文字被拆成两行。

## 4. 场景与素材的精确用法

### 4.1 星空远景

- 只在 shell 内容区域铺设，不盖文字、不拦截点击、不进入辅助技术树。
- 桌面 A01 以 `cover` 保持原始 2:1 比例，定位 `50% 42%`；原图不得非等比拉伸。窄屏 <760 px 使用 A02，定位 `50% 50%`。
- 工作台星图层 opacity 0.62，叠加从左上 `#05060822` 到右下 `#05060899` 的固定遮光层；不改变星图色相，不提高饱和度。
- 工具页/同步/设置 opacity 0.18，收藏列表 0.14，阅读模式 0.06。正文、表单与表格的 surface 不透明，星点不能穿过文字行。
- 禁止再叠加现有大量程序星点和星云。远景默认静止；不做鼠标视差。空间感来自不均匀星野与主体明暗，不靠闪烁。
- 图片失败：纯 `bg` 底色，功能照常；不显示断图标，不反复请求。窗口隐藏立即停绘。

### 4.2 主视觉：恢复原有流动丝线核心

**v1 的“抽象蚀光核”方向被否决，不再执行灰球投影与月面材质方案。** 问题在设计决定本身：它删掉了用户认可的流动与关联感，单纯满足圆角、色值不能弥补。

1. 直接使用 `frontend/src/workspace/core-art.mjs` 的 `drawSilkCore()`，不另写球体或把主视觉变成静态装饰图片。
2. 保留原几何：40 条丝线、每条 144 段、12 级深度明暗、3 条沿表面运动的细高光。保留中空、纤维叠加和慢速形变；不得添加浮动或点击放大。
3. 核心的位置、半径继续由 `sceneLayout()` 决定；全景、两栏、三栏复用同一画布坐标与插值，不分别硬编码一套百分比。
4. 网状节点与核心属于同一层画布，不用静态 icon 方框代替节点。节点前后景的微弱明暗建立空间关系。
5. 暂停、reduced-motion、页面隐藏沿用原组件的停绘/静帧行为；布局变化仍需正确到位，不把停动效变成不能打开内容。
6. 预览直接导入生产组件，仅隔离样式；正式代码保持不变。若后续需改核心亮度，必须与本版对照后单独评审，不擅自换造型。

### 4.3 六模块及连接

模块顺序和路由原样复用 `structure.mjs`，创作台 ID 为 `drafts`，不另造 `studio` 路由。图标用现有 lucide；网状节点保留原球面采样、连线和缓慢转动。

桌面模块卡：148 宽、最小高 82、padding 12×14、圆角 12。画布短屏展开时高 54、padding 7×12；状态 12 px，模块名称 13 px。窄屏卡宽 110、最小高 65。卡片位移完全沿用已有组件，hover/active 不抬升、不缩放。

卡片材质为薄的半透暗表面：`linear-gradient(130deg,#AEBBD112,#06090DB8)`；常态边 `#C3D5EE24`，hover 边 `#BACDE05C`，selected 边 `#BFD2ED80`、底 `#A2BEDB15`。不加宽光晕，不让所有卡片都成为高亮焦点。状态与名称保持不透明。

节点在全景位于标签上方 64 px、半径 46 px；展开后在标签左侧 91 px、半径 29 px（紧凑布局见原函数）。连接线沿用原组件深度渐变与选中态，不改成粗线或删除关系。文字卡与星图不争对比度。

## 5. 页面布局与尺寸

以下尺寸为 CSS px。响应式宽度给出公式，不能把窗口像素宽误当固定设计值。

### 5.1 全局壳与页头

桌面 ≥1100：顶状态条 28 高；shell 左右及下边距 16，height=`100dvh - 44px`，border 1；页头 72 高、左右 padding 24、底边 line 1。左品牌，正中五个主导航，右任务/设置。导航保留单层暗色胶囊：外容器 padding 4、圆角 28、细边 `#A3B6CF24`；单项 88×40、圆角 22、间隔 4。当前项底 `#D4E3F310`、边 `#C4D4EA33`，非当前项透明；不加底部亮条。品牌点击区最小 44 高，标记 32×32、不再带亮边套框。

760～1099：页头 112 高，两行（第一行品牌与右侧操作 48，第二行导航 40，行距 8，垂直边距合计 16）；导航等分可用宽度。<760：shell 边距 8，状态条 24，页头仍两行 112；内边距 12，导航文字 12。小屏不隐藏任务/设置。任何 breakpoint 内导航不换到第三行。

### 5.2 工作台两栏 / 三栏

布局状态、模块相对顺序和面板关系不变。`w/h` 指页头下的实际场景容器，不是浏览器外框。

| 项目 | 两栏展开 | 三栏展开 |
| --- | --- | --- |
| 核心 x | `0.09w` | `0.065w` |
| 模块 x | `max(195,0.29w)` | `max(170,min(0.24w,0.60×leafX))` |
| 中间收藏列表宽 | `0.45w` | `min(520,max(250,0.28w))` |
| 收藏列表 x | `0.53w` | `readerX - 24 - leafWidth` |
| 右详情宽 | 无 | `min(490,max(350,0.31w))` |
| 右详情 x | 无 | `w - readerWidth` |
| 中间/右侧间距 | — | 24 |

这是现有 `scene.mjs` 桌面几何基线，先保持并测试。节点纵向上界 `max(120,0.20h)`、下界 `h-112`，六等分位置不变。窗口变化后统一重新计算，不允许给作品库、收藏库各写一套偏移。若较窄窗口出现卡片与列表重叠，使用下述收敛方式，不能挤压文字：

- <1100：模块详情采用两栏或覆盖式阅读，禁用同时挤入三栏；<760：不展示三栏，收藏使用整宽列表，点击进入整宽详情，返回保留列表位置。
- 极短窗口或200%缩放使场景实际高度 <480 时，不按六个节点硬挤画布：切静态模块导航（整宽列表，每行68、间隔12、容器纵滚），选择后进入对应内容页。保留背景，隐藏连接线；窗口恢复后按同一选中模块恢复正常场景。此为可读性降级，不另造业务结构。
- 画布搜索区：一行操作 32 高、间距 12、搜索 40 高、间距 8、双筛选 36 高；筛选各 `(可用宽-8)/2`。字段过窄时筛选纵排，不缩小文字。
- 第一条内容可点击框顶部位于筛选区底部 +18；Canvas 连接线端点在该行中心。当前 `leaf.top` 的额外 30 是行中心偏移，执行者先核对 DOM anchor，禁止不理解就叠加 30 留出大空白。
- 收藏行高 60，行距 28、节距 88，padding 10/12，标题一行截断、作者与状态一行；长标题完整内容在详情显示。此为画布的节点行，不复制到普通列表。
- 右面板顶部与收藏操作区顶部对齐，下距 16；正文滚动容器独立。面板不挤压整个 Canvas 宽度。

### 5.3 收藏列表与阅读

普通收藏页顶部添加链接条：外边距 16 24，内部 padding 8，输入 40 高，提交主按钮 M；整行最小高 58。链接输入占剩余空间，同步与视图切换保持右侧；<760 时后两个次要操作另成一行，输入与提交仍同一行。不能恢复巨大落地页输入框或添加链接弹窗。

### 6.1 按钮规格

命名简写：P 主按钮、S 次按钮、G 辅助文字按钮、D 危险按钮、I 图标按钮、T 页签、R 可点击行/卡片、K 开关、C 复选框。下表与 §7 联合定义每个按钮，禁止逐页自创样式。

## 8. 运动规范

| 运动 | 数值 | 边界 |
| --- | --- | --- |
| 按钮/边框/文字反馈 | 140 ms，ease-out | 不用 transform；不弹起 |
| 模块首次出现 | opacity 0→1，240 ms ease-out；各模块延迟最多20 ms，总跨度≤100 ms | 不从左上飞入，不缩放；返回首页不重播夸张开场 |
| 首页→模块、模块→首页 | 420 ms，cubic-bezier(.35,0,.65,1) | 正反同一轨迹；中断从当前画面继续 |
| 两栏↔三栏 | 420 ms，同上 | 同一个进度同时插值中栏 x/width、右栏 x/opacity、连线端点；不先卸载右栏再扩宽 |
| 右详情进入 | 目标右边向左24 px至0，opacity 0→1，与列运动同步 | 退出反向，结束才卸载；禁止独立fade导致节奏错位 |
| 普通弹窗 | 160 ms opacity+translateY(6px→0) | 退出120 ms反向；不得缩放弹跳 |
| 菜单 | 120 ms opacity | 不改变页面布局 |
| 核心与节点 | 原组件连续形变与深度明暗 | 保留原速度与形状；暂停有效；不再用整球明暗呼吸替代流动 |

宽度运动只允许用于场景栏位的共享插值；正文不在每帧重新分页或重取数据。绝不动画 blur、大片 box-shadow。快速点击不同模块、收起再打开时不排队播放旧动画。reduced-motion：所有位移和持续运动关闭，状态直接切换，允许≤80 ms淡入；加载状态仍有文字，无须持续旋转。

## 9. 必须达到的验收

1. 1440×900、1280×800、1920×1080、820×1180、390×844 下，功能文字可读、主操作看得见；没有按钮文字图标分两行、点击区覆盖相邻操作、页面横向溢出。
2. 首页、两栏、三栏、完整阅读、同步、任务详情、供应商编辑、添加来源弹窗是同一个视觉系统。截图不能一个绿灰、一个金属蓝、一个黑底白块。
3. 黑色为主体；星野至少在工作台有可辨细节，但按钮与正文阅读不受干扰。核心必须保留原来的中空丝线、层次与流动，六个网状节点与关系线仍可辨；不能退化为灰球或普通方框导航。
4. 普通、悬停、按下、选中、聚焦、禁用、加载、失败均有样张；P/S/D区别可辨。图标和文字颜色成对设置。
5. 每个 B 编号有实施/验证记录；不存在未分类裸按钮。所有承诺“成功”的交互都由真实状态决定。
6. 打开/关闭详情时中栏与右栏同步运动；中间帧无先跳宽、再消失；快速反向不中断到错误位置。
7. 许可、离线素材、无外部CDN、资源失败降级均验证；不把案例商业资产放进包。
8. 功能回归采用隔离样例，不新增真实抖音批量同步和付费模型调用；无改密钥、无改库、无删旧历史。视觉完成与真实业务验收分开记录。

验收留痕与执行顺序见配套文档。本规范的数值是执行目标，任何偏离必须在执行记录里列出旧值、新值、理由与截图，不能让执行 AI 临场自由发挥。
