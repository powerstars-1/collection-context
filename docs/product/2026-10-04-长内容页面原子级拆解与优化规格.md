# 长内容页面：参考原子级拆解与优化规格

日期：2026-10-04。范围：收藏库与资料阅读页的完整布局，包括共享导航和阅读组件。前八节为优化规格；第九节记录用户确认后的实际实现与验收，不能把规格自动等同于全部验收通过。

## 1. 目标与证据口径

产品定位：把用户保存的内容变成可找回、可阅读、可复用、可供个人 AI 引用的资料。浏览收藏库时，重点是找到资料；进入资料时，重点是读懂内容、复制需要的部分、核对来源。

本次拆解按以下顺序展开：定位 → 用户任务 → 页面区域 → 组件 → 字体/颜色/尺寸/间距 → 交互 → 状态 → 响应式 → 验收。

尺寸分三类，禁止混用：

- **参考源码值**：来自官方公开网页 HTML、样式表；代表相应 CSS 规则，未经过当前浏览器 computed style 测量。
- **参考观察**：来自官方界面配图或官方操作说明；配图可能为局部或较早界面，不能据此推断当前完整视口、缩放倍率、精确颜色。
- **本项目拟定值**：针对中文教程、现有组件与个人使用场景制定，须通过实际页面验证。

2026-10-04 本轮浏览器工具在读取现有参考标签页时连续连接超时，未完成新一轮现场 DOM/截图测量。因此不把源码值写成屏幕实测。本项目问题判断依据当前源码与上一轮真实资料截图。公开参考文件只存于当前任务的可视化目录，不进入用户资料库。

### 2.3 飞书妙记：总结、转写与来源核对

参考：[查看妙记](https://www.feishu.cn/hc/zh-CN/articles/022111234449-%E6%9F%A5%E7%9C%8B%E5%A6%99%E8%AE%B0)。

| 原子 | 官方说明的行为 | 采用判断 |

## 3. 本项目的定位与页面层级

### 3.1 用户任务

| 用户此刻想做什么 | 对应入口 | 完成后衔接 |
|---|---|---|
| 留下一条刚看过的内容 | 收藏库顶部单行添加链接 | 保存成功行：打开资料；未提取时可生成笔记 |
| 找回以前看过的教程 | 收藏分类＋全库搜索 | 点击结果进入资料阅读页 |
| 很快知道这条讲什么 | 默认“笔记”页 | 摘要后接操作步骤、提示词等实际内容 |
| 复制一个可用提示词 | 提示词块局部复制 | 复制这一块，不混入元信息和系统提示 |
| 看作者到底说了什么 | “原内容”页 | 选择转写、画面或平台文案 |
| 验证某个结论 | 正文来源引用 | 展开真实来源片段/画面；缺索引时明确说明 |
| 留下自己的想法 | “我的备注”页 | 保存后仍留在本资料，不跳去任务页 |
| 处理未完成内容 | 紧凑状态入口 | 展开缺口；用户明确操作后才重新提取 |

### 3.2 导航层级

1. 全局：收藏库 / 同步 / 设置 / 让 AI 使用。沿用已有 TopNav 组件和路由。
2. 收藏库：全部资料 / 喜欢 / 收藏 / 收藏夹 / 博主作品 / 单条链接。沿用 SubNav。
3. 阅读页：笔记 / 原内容 / 我的备注。
4. 原内容内部：音频转写 / 画面文字 / 图片理解（适用时） / 平台原文；保留已有产物访问。
5. 本文目录：根据当前显示的正文标题生成。它只导航本资料，不承担收藏分类或处理任务导航。

“可读全文”仍是后端/CLI 产物，不作为与总结、转写平级的第六个常驻阅读页签。网页可以在笔记内部提供“完整阅读稿”选项；不得删掉这个产物或改变 AI 读取接口。

## 5. 宽度、页边距与整体布局计算

### 5.1 阅读页宽屏

```text
全局导航（64px）
└─ 收藏库 / 同步 / 设置 / 让 AI 使用           搜索

居中阅读工作区（最大 1016px）
├─ 正文列：最大 760px
│  ├─ 返回、原作品、复制当前内容
│  ├─ 单一标题、作者/来源/入库日期、紧凑状态
│  ├─ 笔记 / 原内容 / 我的备注
│  └─ 摘要 → 章节 → 步骤 → 提示词 → 来源信息
├─ 栏间留白：56px
└─ 本文目录：200px（跟随正文滚动）
```

无目录内容使用 760px 单列居中。阅读时左侧收藏分类收起；浏览收藏库时仍使用原有分类与列表结构。全局导航一直保留。

以 1440px 视口计算：1016px 工作区两侧各约 212px；正文列与目录共享一个居中容器。以 1280px 视口计算：两侧各约 132px。上述是布局目标的几何计算，未算浏览器滚动条等差异，不是参考产品实测。

### 5.2 响应式

| 宽度 | 全局/收藏导航 | 阅读页 | 操作及目录 |
|---|---|---|---|
| ≥1100px | 全局文字导航；收藏库页 200px 分类 | 760px 正文＋56px 留白＋200px 目录；按可用宽度缩小 | 目录在右；按钮正常并排 |
| 768–1099px | 原组件响应式导航；阅读页分类收起 | 正文最大 760px，左右 24px | 目录折叠到正文前，默认收起 |
| 480–767px | 全局项可使用图标，但有名称/辅助标签 | 单列，左右 16px，正文 16px | 局部操作可换行；主页签仍有清晰文字 |
| 320–479px | 保留所有入口，不能以裁切掩盖溢出 | 单列，左右 12px；标题 22px/32px | 触摸目标约 44px；宽表/代码局部横滚 |

200% 字号放大时同样按可用宽度降级。不能把标题截掉或让复制按钮盖住正文。主滚动只有一个；目录过长可以单独滚动，但正文没有额外固定高度框。

## 6. 状态的显示方式

| 状态 | 用户看到什么 | 首要动作 | 正文处理 |
|---|---|---|---|
| 已保存、未提取 | 已保存 · 待生成笔记 | 生成笔记；也可看原内容 | 不显示空白“总结正文” |
| 等待/处理中 | 正在生成笔记/等待生成 | 查看任务 | 已有正文继续阅读 |
| 部分完成 | 笔记部分完成 · 查看缺口 | 展开缺口；按需补充 | 完成部分正常显示，不用多个警告挤走正文 |
| 完成 | 总结可读或对应真实状态 | 阅读/复制 | 不宣称准确率已验证 |
| 总结未生成但转写可读 | 转写可读 · 待总结 | 看转写/生成总结 | 默认打开已有有效内容 |
| 结果过期 | 当前结果需要更新 | 更新笔记 | 保留旧正文并标明，不能藏起来 |
| 文件暂不可读 | 文件暂时无法读取 | 重试读取/查看任务 | 不将缺文件当作“没有收藏” |
| 请求失败 | 读取失败，已有资料未删除 | 重试当前读取 | 保留当前阅读上下文 |
| 不适用 | 无音轨/此类型不适用 | 看其他内容 | 不放付费“重试”按钮 |
| 分页未读完 | 已显示 X / Y 字符 | 继续加载 | 不用“全文”“所有章节”误导 |
| 备注保存冲突 | 备注有新版本 | 重新读取后确认 | 保留编辑文字，不静默覆盖 |
