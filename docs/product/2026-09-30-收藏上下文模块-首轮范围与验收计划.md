## 1. 首轮交付目标

让已有 Personal Agent 通过明确工具查询用户已有收藏，无须人工传整篇文件、无须二次知识库问答。优先证明一个只读闭环：

```text
当前任务 → 搜索命中片段 → 按需读原文/提取结果 → Agent 带来源回答
```

以本机 Codex 先验收，再做 OpenClaw 独立测试会话验证。未经用户指定，不向飞书主动发送消息，不复用日常主会话测试。

## 3. 首个开发切片：三个只读能力

以下为实施前定义的逻辑能力；最终 CLI 名称和 MCP 工具名见 10 月 1 日接入说明。

### 搜索收藏

- 输入：查询词、可选平台/资料范围、结果数量上限。
- 检索：允许范围内的标题、正文、关联转写与画面文字；摘要也可检索，但标记为派生内容。
- 输出：资料引用标识、标题、来源链接、匹配片段、证据类型、处理状态、继续读取所需引用。
- 先实现可解释的关键词召回；Agent 可以拆词或改写后重查。不得把它描述为已实现语义搜索。
- 第一轮不引入向量数据库、持久任务系统或第二个答案模型。

### 分段读取资料

- 输入：工具返回的资料/产物引用、输出长度上限、继续读取位置。
- 输出：原文或提取内容、来源、版本信息、是否截断及后续读取位置。
- 可以分别读取素材卡、转写、画面文字和总结，不默认把所有文件拼成超长上下文。
- 原文件变化时，继续读取需提示版本变化，避免把两个版本的片段混成同一证据。

### 查询处理状态

- 按指定资料检查产物是否存在、是否包含待处理/待核对标记。
- “文件存在”“提取完成”“内容准确”分别表述。
- 当前音频转写不提供精确时间对齐；仅使用已有画面证据的约时间点。
- 不从这个只读入口重试提取或运行流水线。

## 4. 返回契约要求

所有接口应输出结构化 JSON，业务服务与 CLI 共享实现。具体字段在开发时随测试固定，至少覆盖：

- 成功/失败状态和可处理的错误类别。
- 稳定资料引用；内容版本与读取位置另行表示。
- 标题、平台、来源链接、产物类型与相对路径引用。
- 命中片段或正文，以及来源资料/模型整理/用户备注的类型区分。
- 不确定性、处理完整性、截断与继续读取说明。

搜索排序不等同于识别到用户偏好。收藏内容不应默认赋予用户观点身份。

## 5. 最小权限边界

- 初始范围：配置允许的 `00_素材收件箱` 素材和它们在 `80_附件` 内明确关联的文本产物。
- 默认排除模板、运行日志、原始平台响应、登录配置、Agent 协作文件和其他工作目录。
- 不接受任意绝对路径读取；相对路径穿越、附件越界、符号链接逃逸均拒绝。
- 缺失附件、编码异常、关联不确定时返回可诊断状态，不从相邻目录推测另一条资料。
- 不解析或执行资料中的命令。工具只返回资料；Agent 使用说明应标明第三方内容不可信。
- 搜索/读取不输出密钥或读取 `.env`，不启动模型、网络下载或浏览器。

## 6. 验收顺序

### A. 合成资料与自动测试

使用测试临时目录，不写入正式资料库。覆盖：标题与正文检索、转写/OCR命中、摘要类型区分、空结果、中文短词、分页/截断、版本变化、缺失产物、错误关联、路径/符号链接越界、无网络及无模型调用。

相关测试与完整后端测试通过后，记录真实测试结果，不能引用旧的通过数量替代本轮验证。

### B. 真实资料只读检查

从现有收藏中选少量有代表性的资料，人工核对对应的原文与命中位置。至少覆盖画面中的提示词、音频中的解释、只有元数据/处理未完成的资料，以及一个无相关内容的查询。

观察搜索延迟、读取输出量和召回遗漏。不得假设读库过程中零模型调用就代表后续 Agent 回答零费用。

### C. 实际 Agent 调用

一个当前任务触发搜索；Agent 读取命中资料，引用来源并区分事实、推断和缺口。先完成 Codex，再用 OpenClaw 独立会话验证；不声明已支持未测试的 Agent。

### D. 用户效果验收

向用户展示一组具体结果：找到的资料、引用内容、可采取的方法、缺失项。确认这是否比人工翻收藏更有帮助，再决定是否增加语义检索、偏好管理或页面。

## 7. 后续阶段

1. 只读查询闭环通过后，整理 Agent 接入说明与可复用适配。
2. 把现有导入/同步/处理能力与只读入口分权限，补显式操作范围、费用上限和状态回报。
3. 根据实际使用增加排除资料和数据管理入口；偏好推断与确认机制另做设计。
4. 整理干净开源包：自有代码、版本锁定、第三方许可/贡献说明、配置模板、合成/获授权样例、安装与安全文档。
5. 干净环境安装与外部试用通过后，再录制发布演示和创建公开 GitHub 项目。

完整前端、独立聊天系统、多租户、商业支付、自动发布、其他个人数据源均不进入首轮。

## 8. 发布前演示原则

建议用一个真实需求展示“当前任务 → 找到曾经收藏的资料 → 引用方法 → 实际尝试”。不宣传全量收藏准确提取、AI已全面了解用户、永久免费、任意Agent即插即用或精准定位全部音频时间。

演示中的个人信息应脱敏；原始视频和文章不默认随开源仓库再分发。公开发布、外部消息发送和计费批处理仍需具体授权。
