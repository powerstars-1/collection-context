# 收藏上下文能力层 · 本地工作项目

## 当前开发入口（2026-10-08）

当前新版是 **CollectionContext / 创作空间**：自有 Python 后端 + React 工作台，首发业务为抖音收藏、同步、提取和阅读。不是已经完成历史库迁移的正式发行版。

**云端接手先读 [开发进度与云环境交接](docs/product/2026-10-08-开发进度与云环境交接.md)。** 其中包含当前能力、未完成项、安装/测试/启动命令及本次验证结果。新版源码入口是 `backend/src/collection_context/` 与 `frontend/src/`；不要把下面的旧生产流程说明当成新版运行依赖。

私人资料库、登录态、API Key、旧服务运行数据与本机运维配置不随 Git 同步。云端开发使用独立空库或原创测试样例；不能通过连接 GitHub 自动接管 Mac 上的真实收藏。当前私有开发仓库不等于公开开源发行。

## 目录职责

| 目录 | 职责 | 本轮处理 |
| --- | --- | --- |
| `backend/` | 自有 CLI、适配器、媒体提取、测试 | 保留代码与运行环境 |
| `docs/product/` | 当前产品决策、只读查询计划、验证记录 | 现行方案与历史规划分开 |
| `docs/content-strategy/` | 内部账号、分析、写作、协作规则 | 保留；不是开源产品必需依赖 |
| `docs/archive/` | 历史产品规划 | 只作历史参考，不作为开发指令 |
| `content-vault/` | 个人素材、附件、稿件、创意项目、协作记录 | 私有资产，完整保留 |
| `data/` | 原始响应、去重索引、分析包、运行状态 | 私有运行数据，完整保留 |
| `downloads/` | 手动下载与创作实验产物 | 保留素材；移出抓取调试文件 |
| `infra/` | 本机后台守护、公众号服务、服务器运维资料 | 保留，不调整部署 |
| 第三方工作副本 | 平台同步依赖或方法参考 | 保留原路径；发布前单独核对许可与安装方式 |

第三方目录包括 `dYm`、`All-IN-ONE`、`we-mp-rss`、`last30days-skill`、`TrendRadar`、`cheat-on-content`、`khazix-skills`。其中 dYm、All-IN-ONE 和 last30days 的现有适配器包含本地路径依赖，不能仅因目录多就删除或改名。
