# 收藏上下文前端

本目录现在交付用户在 2026-10-06 确认的「创作空间」工作台，保留已验收的画布结构、材质与双向动效。生产入口为 `src/App.jsx → src/workspace/Workbench.jsx`，直接调用自有 `collection_context` 后端，不依赖结构样稿服务器。原有白色页面和旧导航、列表组件已经退役；通用的真实同步、任务、模型设置、阅读和资料管理能力保留并接入同一套视觉。

早期界面曾参考用户提供的 [creator-sync-cloud-v1](https://github.com/powerstars-1/creator-sync-cloud-v1)，来源版本 `6a9c3a9`；现存引用的归属和许可继续保留。

## 页面与能力

- 工作台 `/#workspace`：六个模块的画布入口。收藏库接入真实资料；概念网络、方法库、作品库、选题池、创作台明确显示「规划中」，不制造假数据。
- 收藏库 `/#library`：顶部单行链接保存、真实搜索和来源过滤、版本绑定的分页。选中资料读取总结、转写、画面、原文、完整阅读稿与备注；可展开阅读并返回原位置。
- 同步与任务 `/#sync`、`/#tasks`：已授权账号和来源范围、真实保存记录及任务状态。自动同步和模型处理分别配置，历史批次与重新计费须确认。
- 设置 `/#settings/models`：真实供应商目录、自定义兼容接口、三类模型选择和现有凭据状态。保存配置不代表模型已验证，页面不自行发起收费检测。
- AI 接入 `/#settings/ai`、单条 `/#ai/<material_ref>`：复制带来源的已保存内容，或获取当前库的 CLI 接入说明；不把管理权限交给普通查询客户端。
- 原 `/connect`、`/activity`、`/settings`、`/access` 及 `/?ref=...` 链接自动映射到上述入口，不再提供另一套旧页面。

所有页面和图片调用同一个 `collection_context` 后端的本站 `/v1/` 接口，共用有界请求队列。当前本机验收入口为 `http://127.0.0.1:8790/#workspace`，使用已有独立测试库的真实资料和配置，不读取样稿假数据、不切换私人生产库。旧 `8814` 结构样稿不再作为运行入口。

单条缺原媒体时，「提取内容」先提供「只保存这一条的媒体」，后台完成后再显示模型处理计划，需用户另行确认才会调用收费模型，不要求重新同步整个收藏夹。

## 开发与打包

前端页面本身不需要另起 Node.js 服务：构建后的静态 HTML、JavaScript 和 CSS 随 Python 包分发，由后端同源提供。开发构建需要 Node.js；后端启用 Pi 模型适配时还需要 Node.js 22+ 执行独立 worker，不能将“前端不需 Node 服务”理解为所有模型功能都无 Node 依赖。

```sh
cd frontend
npm ci
npm test
npm run build
```

构建入口为 `build.mjs`，最终静态资源位于 `backend/src/collection_context/interfaces/assets/`。不要手工改编译后的文件，应修改本目录源码再构建。依赖版本固定在 `package.json` 和锁文件中；更新依赖后重新构建、运行前后端相关测试并检查实际页面。

## 安全边界

- API transport 只允许本站 `/v1/`；会话使用同源 Cookie，非 GET 请求带 CSRF 校验。
- 访问凭据不写入 localStorage 或 sessionStorage；密钥输入不回显，退出或提交后清空。
- 模型配置只提交至本地管理后端，前端不直接请求供应商或上传视频、音频、图片。
- 内容通过 React 文本绑定或 DOM `textContent` 展示，不作为 HTML 注入。
- 管理权限以真实后端会话为准；页面按钮不替代后端权限与费用确认。
- 前端迁移不授权公开发布、切换私人生产库、批量收费或删除旧服务。
