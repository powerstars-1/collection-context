# 收藏上下文前端

本目录使用用户提供的 [creator-sync-cloud-v1](https://github.com/powerstars-1/creator-sync-cloud-v1) 前端作为界面底座，来源版本 `6a9c3a9`。直接保留原 React 顶部导航、侧栏、工作台双栏和素材列表组件，调整产品标签、资料字段与请求接线。不是只复制配色，也不依赖原项目的运行后台。

## 页面与能力

- 收藏库 `/`：搜索资料，读取正文、音频转写、画面文字、总结及来源、处理状态。资料作为文本展示，不能触发命令或模型执行。
- 同步与处理 `/connect`、`/activity`：登记单条作品、管理已授权来源、查看任务；自动同步与模型处理分别配置，历史批次、上传和重新计费仍需明确确认。
- 设置 `/settings`：用户自行提供云端音频、图像、汇总接口。保存配置不代表模型或密钥已验证，不自行调用收费模型。
- AI 接入 `/access`：说明只读查询和受控读取，以及 CLI/MCP 的调用方式；不把主人管理权限交给普通 AI 查询客户端。

所有页面调用同一个 `collection_context` 后端的本站 `/v1/` 接口。未接入原项目的 Redis、发布、飞书及其他生产能力，也不会启动原私人库的全量同步。当前演示资料与私人生产库隔离。

## 开发与打包

Node.js 只用于开发和构建；终端用户运行 Python 后端发行包时不需要 Node.js、前端开发服务器或另外一套业务服务。构建后的静态 HTML、JavaScript 和 CSS 随 Python 包分发，由后端同源提供。

```sh
cd frontend
npm ci
npm test
npm run build
```

构建入口为 `build.mjs`，最终静态资源位于 `backend/src/collection_context/interfaces/assets/`。不要手工改编译后的文件，应修改本目录源码再构建。依赖版本固定在 `package.json` 和锁文件中；更新依赖后重新构建、运行前后端相关测试并检查实际页面。

## 安全边界

- API transport 只允许本站 `/v1/`；会话使用同源 Cookie，非 GET 请求带 CSRF 校验。
- 访问凭据不写入 localStorage 或 sessionStorage；密钥输入不回显，退出或提交后清空。
- 模型配置只提交至本地管理后端，前端不直接请求供应商或上传视频、音频、图片。
- 内容通过 React 文本绑定或 DOM `textContent` 展示，不作为 HTML 注入。
- 管理权限以真实后端会话为准；页面按钮不替代后端权限与费用确认。
- 前端迁移不授权公开发布、切换私人生产库、批量收费或删除旧服务。

## 测试范围

`tests/*.test.mjs` 使用 Node 内置测试运行器，核对原组件结构/样式保留、安全规则和共享 API transport 的行为。此类契约测试不是视觉验收，也不证明真实平台同步、音频转写、OCR、模型质量或跨平台运行已通过；这些需要独立实测和验收记录。

来源组件归属注释保留，来源仓库的 MIT 声明见 `THIRD_PARTY_NOTICES.md`，构建时一并放入后端发行资源。公开发布前仍须完成完整依赖许可及开源安全检查，本轮不直接发布 GitHub。
